Express middleware

This function is an Express middleware. Middleware is a function that runs before your main route handler. Its job is to make sure the request contains all the information needed before continuing.

Why do this?

Older versions of your backend expected:


req.headers.platform

But newer clients (like your React web app) send:


req.body.platform

Instead of changing all the existing backend code, this middleware copies the values into req.headers, keeping the rest of the code unchanged.

if (!validateHeaders(req, res, requiredHeaders)) {

}

This checks that every required value is now present.

It verifies:

  • code
  • device_id
  • device_token_id

If any are missing, validateHeaders() sends an error response, for example:

If everything is valid, Express moves on to the next middleware or your controller.

In simple terms

Think of this middleware as a translator and security guard:

  • Translator: If the client sends data in the JSON body instead of HTTP headers, it copies that data into the headers so the existing backend code can continue working without modification.
  • Security guard: It checks that all required values are present before allowing the request to proceed.
  • Traffic controller: If everything looks good, it calls next() to let the request continue to the sign-in logic. Otherwise, it stops the request and returns an error.

This function checks whether all required headers are present in the request. If any are missing, it sends an error back to the client.

Let's go through it step by step.


/**
 * Utility: Validate required headers
 */

function validateHeaders(req, res, requiredHeaders) {
    const missing = requiredHeaders.filter((header) => {
        const value = req.headers[header];
        return value === undefined || value === null;
    });

    if (missing.length > 0) {
        return res.status(403).send({
            status: false,
            statusCode: 403,
            message: `Missing required headers: ${missing.join(", ")}`,
            data: [],
        });
    }

    return true;
}
