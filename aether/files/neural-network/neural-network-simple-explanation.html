Neural Network

A neural network is a mathematical system that learns patterns from data.

Simple Explanation

A neural network is a mathematical system that learns patterns from data.

Think of it like a huge collection of tiny calculators (neurons). Each calculator:

  1. Receives numbers as input.
  2. Multiplies them by importance values called weights.
  3. Adds them together.
  4. Passes the result through a function that decides how much information to send forward.

Example:

Suppose you want to predict house prices.

Inputs:

  • House size = 100 sqm
  • Bedrooms = 3

The neural network might learn:


score = (100 × 5000) + (3 × 100000)
      = 800000

This is a very simplified neural network.

The key mathematical techniques are:

  • Linear Algebra (vectors and matrices)
  • Calculus (derivatives and gradients)
  • Probability & Statistics
  • Optimization (finding the best weights)

Detailed Explanation

1. Linear Algebra

Neural networks mainly operate on vectors and matrices.

Input Vector

Suppose:


x = [100, 3]

where:

  • 100 = house size
  • 3 = bedrooms

Weight Vector


w = [5000, 100000]

The network computes:


z = w·x

Dot product:


z = (100 × 5000) + (3 × 100000)
z = 800000

This is the first mathematical operation inside a neuron.

2. Bias

Neurons also learn an additional value called bias.

Formula:


z = wx + b

Example:


z = 800000 + 50000
z = 850000

Bias helps shift predictions up or down.

3. Activation Functions

If neurons only performed multiplication and addition, the network would just be one big linear equation.

Activation functions add non-linearity.

ReLU

Most common:


ReLU(x) = max(0, x)

Examples:


ReLU(5) = 5
ReLU(-5) = 0

This allows neural networks to learn complex patterns.

4. Matrix Multiplication

Real neural networks process thousands of inputs simultaneously.

Instead of:


z = wx + b

we use:


Z = XW + B

Where:


X = input matrix
W = weight matrix
B = bias matrix

Example:


X =
[100  3]
            

W =
[5000
 100000]

Output:


Z = XW
= 800000

Modern GPUs are optimized for this operation.

6. Calculus (Derivatives)

The network must determine:

Which weight caused the error?

This is where derivatives are used.

Derivative:


dLoss/dWeight

Meaning:

If I change this weight slightly, how much will the loss change?

Large derivative:


Weight is very important.

Small derivative:

Weight has little effect.

7. Gradient Descent

After calculating derivatives, weights are updated.

Formula:


new_weight =
old_weight - learning_rate × gradient

Example:


weight = 5000
gradient = 50
learning_rate = 0.01
            

new_weight =
5000 - (0.01 × 50)
            

4999.5

The network keeps adjusting weights to reduce error.

8. Backpropagation

This is the main learning algorithm.

Process:


Forward Pass
    ↓
Prediction
    ↓
Compute Loss
    ↓
Compute Gradients
    ↓
Update Weights
    ↓
Repeat

Backpropagation uses the Chain Rule from calculus.

Chain Rule:


dL/dW =
(dL/dY) ×
(dY/dZ) ×
(dZ/dW)

This efficiently computes gradients for millions or billions of parameters.

9. Probability

For classification tasks:

Example:

Cat vs Dog

Output:


Cat = 0.9
Dog = 0.1

The network converts raw scores into probabilities using:

Softmax


P(class) =
e^x / Σ(e^x)

Result:


Cat = 90%
Dog = 10%

10. Optimization Algorithms

Instead of basic gradient descent, modern AI uses advanced optimizers.

Popular ones:

  • SGD
  • Momentum
  • RMSProp
  • Adam

Adam

Used by most modern neural networks including transformer training.

It automatically adjusts learning rates for each parameter.

How ChatGPT Uses These Techniques

A transformer model like OpenAI's GPT combines:

  1. Linear Algebra
    • Huge matrix multiplications.
  2. Calculus
    • Backpropagation.
  3. Probability
    • Predict next word probabilities.
  4. Optimization
    • Adam optimizer.
  5. Information Theory
    • Cross-entropy loss.

A simplified training cycle:


Input:
"The sky is"

Model predicts:
"green"

Actual:
"blue"

Loss computed
      ↓
Backpropagation
      ↓
Update billions of weights
      ↓
Model improves

After seeing trillions of examples, the network learns language patterns, reasoning patterns, coding patterns, and world knowledge.

In one sentence:

A neural network is essentially a very large mathematical function that uses linear algebra to make predictions, calculus to measure mistakes, and optimization algorithms to continuously adjust its weights until it learns useful patterns from data.
