Core Features of UITableView

UITableView is one of the core UI components in UIKit for displaying vertically scrolling lists in iOS apps. It is highly optimized, reusable, and supports dynamic content.

Core Features of UITableView

1. Reusable Cells

Instead of creating a new view for every row, table views reuse cells for performance.


tableView.dequeueReusableCell(withIdentifier: "Cell", for: indexPath)

Benefits:

  • Lower memory usage
  • Smooth scrolling
  • Efficient rendering

2. Sections and Rows

A table can be divided into sections.

Example:

  • Section 0 → Favorites
  • Section 1 → Recent

Structure:


func numberOfSections(in tableView: UITableView) -> Int
func tableView(_ tableView: UITableView, numberOfRowsInSection section: Int) -> Int

3. Multiple Cell Styles

Built-in styles:

  • .default
  • .subtitle
  • .value1
  • .value2

Or use custom cells.


UITableViewCell(style: .subtitle, reuseIdentifier: "Cell")

4. Custom Cells

You can subclass UITableViewCell to create complex layouts.

Example:

  • Profile image
  • Title
  • Subtitle
  • Buttons
  • Toggle switches

class UserCell: UITableViewCell {
    @IBOutlet weak var nameLabel: UILabel!
}

5. Dynamic Row Heights

Automatic sizing based on content.


tableView.rowHeight = UITableView.automaticDimension
tableView.estimatedRowHeight = 100

Useful for:

  • Chat apps
  • Social feeds
  • Multi-line text

6. Editing Support

Supports:

  • Delete
  • Insert
  • Reorder

Example delete:


func tableView(_ tableView: UITableView,
               commit editingStyle: UITableViewCell.EditingStyle,
               forRowAt indexPath: IndexPath) {

    if editingStyle == .delete {
        data.remove(at: indexPath.row)
        tableView.deleteRows(at: [indexPath], with: .automatic)
    }
}

7. Swipe Actions

Modern contextual actions.


func tableView(_ tableView: UITableView,
 trailingSwipeActionsConfigurationForRowAt indexPath: IndexPath)
-> UISwipeActionsConfiguration?

Examples:

  • Delete
  • Favorite
  • Archive

8. Selection Handling

Detect row taps.


func tableView(_ tableView: UITableView,
    didSelectRowAt indexPath: IndexPath)

Used for:

  • Navigation
  • Detail screens
  • Option selection

9. Headers and Footers

Per-section headers and footers.


func tableView(_ tableView: UITableView,
    titleForHeaderInSection section: Int) -> String?

Or use custom views.

10. Pull to Refresh

Built-in refresh control.


let refreshControl = UIRefreshControl()
tableView.refreshControl = refreshControl

Common in:

  • Feeds
  • Email apps
  • News apps

11. Prefetching

Loads data before cells appear.


UITableViewDataSourcePrefetching

Useful for:

  • Infinite scrolling
  • Image loading
  • API pagination

12. Animations

Animated updates:


tableView.insertRows(at: [indexPath], with: .fade)
tableView.reloadRows(at: [indexPath], with: .automatic)

Animation types:

  • .fade
  • .automatic
  • .left
  • .right

13. Diffable Data Source (Modern API)

Modern safer data updates.


UITableViewDiffableDataSource

Advantages:

  • Easier state management
  • Automatic animations
  • Prevents sync crashes

14. Search Integration

Works with UISearchController.


navigationItem.searchController = searchController

Supports:

  • Live filtering
  • Search suggestions

15. Accessibility Support

Built-in support for:

  • VoiceOver
  • Dynamic Type
  • Accessibility labels

Important for inclusive apps.

Basic UITableView Setup

Simple Example


import UIKit

class ViewController: UIViewController,
                      UITableViewDataSource,
                      UITableViewDelegate {

    let tableView = UITableView()
    let items = ["Apple", "Banana", "Orange"]

    override func viewDidLoad() {
        super.viewDidLoad()

        view.addSubview(tableView)
        tableView.frame = view.bounds

        tableView.dataSource = self
        tableView.delegate = self

        tableView.register(UITableViewCell.self,
                           forCellReuseIdentifier: "Cell")
    }

    func tableView(_ tableView: UITableView,
                   numberOfRowsInSection section: Int) -> Int {
        items.count
    }

    func tableView(_ tableView: UITableView,
                   cellForRowAt indexPath: IndexPath)
    -> UITableViewCell {

        let cell = tableView.dequeueReusableCell(
            withIdentifier: "Cell",
            for: indexPath
        )

        cell.textLabel?.text = items[indexPath.row]

        return cell
    }

    func tableView(_ tableView: UITableView,
                   didSelectRowAt indexPath: IndexPath) {

        print(items[indexPath.row])
    }
}

UITableView vs UICollectionView

Feature UITableView UICollectionView
Vertical lists Excellent Good
Grid layouts Limited Excellent
Simplicity Easier More flexible
Complex layouts Moderate Best
Modern UI Okay Preferred

Today many modern apps prefer UICollectionView with compositional layouts because it is more flexible, but UITableView is still excellent for structured vertical lists and settings-style interfaces.
