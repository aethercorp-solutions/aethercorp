Swift Combine

Swift Combine is Apple’s framework for handling asynchronous events (things that happen over time) in a clean, reactive way.

Simple idea

Instead of writing complex callbacks like:

  • completion handlers
  • delegates
  • notification observers

Combine lets you say:

“When data changes, automatically react to it.”

🧠 Core concept (easy version)

Combine is like a pipeline:

1. Publisher

This is the source of data

  • Example: API call, text input, button tap
  • It “publishes” values over time

Just("Hello")

👉 This publishes a single value: "Hello"

2. Subscriber

This is the receiver

  • It listens for values from the publisher

.sink { value in
    print(value)
}

3. Operators

These transform data in between

Example: change text to uppercase


Just("hello")
    .map { $0.uppercased() }
    .sink { print($0) }

Output:


HELLO

🔁 Real-world example

Imagine:

  • User types in a search bar
  • You want to filter results live

Combine flow:


TextField → Publisher → Transform → API call → UI update

⚡ Why Combine is useful

  • Removes nested callbacks (“callback hell”)
  • Makes async code more readable
  • Works well with SwiftUI
  • Handles streams of data (not just single responses)

📦 Simple mental model

Think of it like:

  • 🎤 Publisher = microphone
  • 🎧 Subscriber = listener
  • 🎚️ Operators = audio effects in between

Here’s a simple Combine API call example in Swift (clean and commonly used in MVVM apps).

🌐 Example: Fetch Users from API using Combine

We’ll call a fake API:


https://jsonplaceholder.typicode.com/users

1. Model


struct User: Codable {
    let id: Int
    let name: String
    let email: String
}

2. API Service (Combine Network Layer)


import Foundation
import Combine

class APIService {

    func fetchUsers() -> AnyPublisher<[User], Error> {

        let url = URL(string: "https://jsonplaceholder.typicode.com/users")!

        return URLSession.shared.dataTaskPublisher(for: url)
            .map { $0.data } // extract data
            .decode(type: [User].self, decoder: JSONDecoder()) // decode JSON
            .receive(on: DispatchQueue.main) // update UI on main thread
            .eraseToAnyPublisher() // hide complexity
    }
}

3. ViewModel (Using Combine)


import Foundation
import Combine

class UserViewModel: ObservableObject {

    private var cancellables = Set()
    private let service = APIService()

    @Published var users: [User] = []
    @Published var errorMessage: String?

    func loadUsers() {

        service.fetchUsers()
            .sink(receiveCompletion: { completion in
                switch completion {
                case .finished:
                    break
                case .failure(let error):
                    self.errorMessage = error.localizedDescription
                }
            }, receiveValue: { users in
                self.users = users
            })
            .store(in: &cancellables)
    }
}

4. How it works (simple flow)


API URL
   ↓
URLSession Publisher
   ↓
map → extract data
   ↓
decode → convert JSON to Swift model
   ↓
receive(on main thread)
   ↓
sink → update UI

⚡ Key Combine concepts used here

  • dataTaskPublisher → makes API call
  • map → transforms response
  • decode → JSON → Swift model
  • sink → receives result
  • AnyCancellable → keeps subscription alive
  • @Published → updates UI automatically (SwiftUI-friendly)

🧠 Simple mental model

“Start request → transform data → decode → deliver to UI → react automatically”
