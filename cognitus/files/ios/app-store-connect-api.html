App Store Connect API

The App Store Connect API is Apple's official REST API that allows you to automate many tasks that you would normally perform manually in App Store Connect.

It is primarily used in CI/CD pipelines (GitHub Actions, Bitrise, Jenkins, Azure DevOps, etc.) to automate app releases, TestFlight management, and App Store operations.

What can it do?

Some common automation tasks include:

TestFlight

  • Update TestFlight "What's New" release notes
  • Add or remove beta testers
  • Create beta tester groups
  • Assign builds to beta groups
  • Update beta review information
  • Submit builds for beta review

Example:

Instead of manually typing:


What's New

- Fixed login issue
- Improved performance
- Added dark mode

your CI/CD pipeline can automatically upload it after every build.

App Store Releases

You can automate:

  • Create a new app version
  • Update App Store descriptions
  • Keywords
  • Screenshots
  • Promotional text
  • Copyright
  • Release notes
  • Submit for review
  • Schedule release

Build Management

Manage builds by:

  • Listing builds
  • Retrieving build information
  • Assigning builds to versions
  • Expiring TestFlight builds

Testers

Manage:

  • Internal testers
  • External testers
  • Beta groups

Analytics

Access:

  • Downloads
  • Sales reports
  • Subscription reports
  • Financial reports

Authentication

Unlike older Apple APIs that relied on Apple ID credentials, the App Store Connect API uses JWT (JSON Web Tokens).

You create an API key in App Store Connect, which provides:

  • Key ID
  • Issuer ID
  • Private key (.p8)

Your automation generates a signed JWT and uses it to authenticate API requests.

Example Workflow

A typical automated release pipeline looks like this:


    GitHub Actions

        │
        ▼

Build iOS App

        │
        ▼

Archive

        │
        ▼

Upload IPA

        │
        ▼

Wait until Apple processes build

        │
        ▼

App Store Connect API
      │
      ├── Update TestFlight Notes
      ├── Add Build to Beta Group
      ├── Submit for Beta Review
      └── Notify Slack

No one needs to log into App Store Connect to perform these repetitive tasks.

Example API Request

To update TestFlight release notes, you send a request like:


PATCH https://api.appstoreconnect.apple.com/v1/betaBuildLocalizations/{id}

Authorization: Bearer 

{
  "data": {
    "type": "betaBuildLocalizations",
    "id": "...",
    "attributes": {
      "whatsNew": "Fixed offline sync.\nImproved performance."
    }
  }
}

Typical CI/CD Example

1. Build the app:


xcodebuild archive

2. Upload to App Store Connect:


xcrun altool --upload-app ...

or


xcrun iTMSTransporter

3. Wait for the build to finish processing.

4. Use the App Store Connect API to:

  • find the uploaded build
  • locate its beta localization
  • update the What's New field
  • optionally assign it to a TestFlight group

This entire process can run automatically after every successful build.

Benefits

  • No manual edits in App Store Connect
  • Consistent release notes
  • Fully automated TestFlight deployments
  • Easy integration with GitHub Actions, Bitrise, Jenkins, Azure DevOps, and Fastlane
  • Secure authentication using API keys instead of Apple ID credentials

If your goal is to automatically populate TestFlight release notes from Xcode or your CI/CD pipeline, the App Store Connect API is Apple's recommended solution. You typically upload the build first, wait until Apple finishes processing it, then use the API to update the TestFlight "What's New" text before distributing the build to testers.
