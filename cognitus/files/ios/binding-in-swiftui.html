@Binding in SwiftUI

@Binding in SwiftUI is commonly used when a child view needs to read and modify state owned by a parent view.

In real-world apps, @Binding is everywhere:

  • Forms
  • Toggles
  • Modals
  • Navigation
  • Filters
  • Settings
  • Custom components
  • Editable lists
  • Search bars

Real Project Example — E-commerce Cart Quantity

This is a practical app architecture pattern.

Parent View (Owns the State)


import SwiftUI

struct CartView: View {
    
    @State private var quantity: Int = 1
    
    var body: some View {
        VStack(spacing: 20) {
            
            Text("Quantity: \(quantity)")
                .font(.title)
            
            QuantitySelector(quantity: $quantity)
            
            Text("Total: $\(quantity * 499)")
                .font(.headline)
        }
        .padding()
    }
}

Child View (Edits Parent State)


import SwiftUI

struct QuantitySelector: View {
    
    @Binding var quantity: Int
    
    var body: some View {
        HStack(spacing: 20) {
            
            Button("-") {
                if quantity > 1 {
                    quantity -= 1
                }
            }
            
            Text("\(quantity)")
                .font(.title2)
            
            Button("+") {
                quantity += 1
            }
        }
    }
}

Why @Binding Is Important

Without @Binding:

  • Child views cannot directly update parent state
  • You would need callbacks/closures everywhere
  • State management becomes messy

With @Binding:

  • Single source of truth
  • Cleaner architecture
  • Reusable components
  • Better separation of concerns

Real App Scenarios

1. Login Form


struct LoginView: View {

    @State private var email = ""
    
    var body: some View {
        EmailField(email: $email)
    }
}
            

struct EmailField: View {

    @Binding var email: String
    
    var body: some View {
        TextField("Email", text: $email)
    }
}

2. Settings Screen Toggle


struct SettingsView: View {

    @State private var notificationsEnabled = false
    
    var body: some View {
        NotificationToggle(
            isEnabled: $notificationsEnabled
        )
    }
}

3. Search Bar Component


struct HomeView: View {

    @State private var searchText = ""
    
    var body: some View {
        SearchBar(text: $searchText)
    }
}

4. Modal Presentation


struct DashboardView: View {

    @State private var showProfile = false
    
    var body: some View {
        
        Button("Open Profile") {
            showProfile = true
        }
        .sheet(isPresented: $showProfile) {
            ProfileView(showProfile: $showProfile)
        }
    }
}

Child:


struct ProfileView: View {

    @Binding var showProfile: Bool
    
    var body: some View {
        Button("Close") {
            showProfile = false
        }
    }
}

Important Concept

@State

Owns the data.


@State private var username = ""

@Binding

References data owned elsewhere.


@Binding var username: String

The $ Symbol

This creates a binding.


$username

Meaning:

“Pass a reference to this state.”

“Pass a reference to this state.”
