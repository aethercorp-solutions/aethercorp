Implementing refresh tokens in a Swift iOS app

Implementing refresh tokens in a Swift iOS app is basically about keeping the user logged in without asking them to sign in again when the access token expires.

Here’s the standard production approach used in most iOS apps.

🧠 Core Idea

You usually have:

  • Access Token (short-lived) → expires in minutes (e.g. 15 min)
  • Refresh Token (long-lived) → expires in days/weeks

When API returns 401 Unauthorized, you:

  1. Use refresh token
  2. Get a new access token
  3. Retry the original request

🏗️ Recommended Architecture

You need 3 parts:

1. Token Storage (Keychain)

Never store tokens in UserDefaults.


final class TokenStorage {
    static let shared = TokenStorage()

    func saveAccessToken(_ token: String) {
        KeychainHelper.save(key: "accessToken", value: token)
    }

    func saveRefreshToken(_ token: String) {
        KeychainHelper.save(key: "refreshToken", value: token)
    }

    func getAccessToken() -> String? {
        KeychainHelper.read(key: "accessToken")
    }

    func getRefreshToken() -> String? {
        KeychainHelper.read(key: "refreshToken")
    }
}

🌐 2. API Client with Auto Refresh

This is the most important part.

URLSession interceptor pattern


final class APIClient {

    static let shared = APIClient()

    private let session = URLSession.shared
    private var isRefreshing = false
    private var requestsToRetry: [(Bool) -> Void] = []

    func request(_ urlRequest: URLRequest,
                    completion: @escaping (Data?, URLResponse?, Error?) -> Void) {

        var request = urlRequest

        // Attach access token
        if let token = TokenStorage.shared.getAccessToken() {
            request.setValue("Bearer \(token)", forHTTPHeaderField: "Authorization")
        }

        session.dataTask(with: request) { data, response, error in

            if let httpResponse = response as? HTTPURLResponse,
                httpResponse.statusCode == 401 {

                self.handle401(request: request, completion: completion)
                return
            }

            completion(data, response, error)

        }.resume()
    }
}

🔄 3. Refresh Token Logic


extension APIClient {

    private func handle401(request: URLRequest,
                            completion: @escaping (Data?, URLResponse?, Error?) -> Void) {

        requestsToRetry.append { [weak self] success in
            guard success else {
                completion(nil, nil, NSError(domain: "Auth", code: 401))
                return
            }

            self?.request(request, completion: completion)
        }

        guard !isRefreshing else { return }

        isRefreshing = true

        refreshAccessToken { success in
            self.isRefreshing = false

            self.requestsToRetry.forEach { $0(success) }
            self.requestsToRetry.removeAll()
        }
    }
}

🔑 4. Refresh Token API Call


extension APIClient {

    private func refreshAccessToken(completion: @escaping (Bool) -> Void) {

        guard let refreshToken = TokenStorage.shared.getRefreshToken() else {
            completion(false)
            return
        }

        var request = URLRequest(url: URL(string: "https://api.yourapp.com/auth/refresh")!)
        request.httpMethod = "POST"
        request.setValue("application/json", forHTTPHeaderField: "Content-Type")

        let body = ["refreshToken": refreshToken]
        request.httpBody = try? JSONSerialization.data(withJSONObject: body)

        session.dataTask(with: request) { data, response, error in

            guard
                let data,
                let json = try? JSONSerialization.jsonObject(with: data) as? [String: Any],
                let newAccessToken = json["accessToken"] as? String
            else {
                completion(false)
                return
            }

            TokenStorage.shared.saveAccessToken(newAccessToken)

            // optionally rotate refresh token
            if let newRefresh = json["refreshToken"] as? String {
                TokenStorage.shared.saveRefreshToken(newRefresh)
            }

            completion(true)

        }.resume()
    }
}

🧩 How Flow Works

  1. App sends API request
  2. Server responds:
    • 200 → success
    • 401 → token expired
  3. iOS:
    • calls refresh endpoint
    • gets new token
    • retries original request automatically

🔐 Best Practices (important)

✅ Always use Keychain

Never store tokens in plaintext storage.

✅ Prevent multiple refresh calls

Handled with:


isRefreshing + request queue

✅ Rotate refresh tokens (if backend supports it)

✅ Handle refresh failure

If refresh fails → logout user.

⚡ Alternative (Cleaner Modern Approach)

If you're using:

  • Combine
  • Alamofire
  • Moya

You can implement this as a RequestInterceptor, which is cleaner than manual retry logic.

Using Combine makes refresh-token handling much cleaner because you can chain requests, retry automatically, and centralize auth logic.

🌐 2. AuthService (Refresh Token Publisher)

This is where Combine shines.


import Combine
import Foundation

final class AuthService {

    static let shared = AuthService()
    private let session = URLSession.shared

    func refreshToken() -> AnyPublisher<String, Error> {

        guard let refreshToken = TokenStorage.shared.getRefreshToken() else {
            return Fail(error: URLError(.userAuthenticationRequired))
                .eraseToAnyPublisher()
        }

        var request = URLRequest(url: URL(string: "https://api.yourapp.com/auth/refresh")!)
        request.httpMethod = "POST"
        request.setValue("application/json", forHTTPHeaderField: "Content-Type")

        let body = ["refreshToken": refreshToken]
        request.httpBody = try? JSONSerialization.data(withJSONObject: body)

        return session.dataTaskPublisher(for: request)
            .tryMap { data, response in
                guard let http = response as? HTTPURLResponse,
                      (200..<300).contains(http.statusCode) else {
                    throw URLError(.badServerResponse)
                }
                return data
            }
            .decode(type: RefreshResponse.self, decoder: JSONDecoder())
            .map { response in
                TokenStorage.shared.saveAccessToken(response.accessToken)

                if let newRefresh = response.refreshToken {
                    TokenStorage.shared.saveRefreshToken(newRefresh)
                }

                return response.accessToken
            }
            .eraseToAnyPublisher()
    }
}

Response model


struct RefreshResponse: Codable {
    let accessToken: String
    let refreshToken: String?
}

🚀 3. API Client with Auto Refresh (Combine Core)

This is the most important part.


import Combine
import Foundation

final class APIClient {

    static let shared = APIClient()
    private let session = URLSession.shared

    private var cancellables = Set<AnyCancellable>()
    private var isRefreshing = false
    private var pendingRequests: [(Bool) -> Void] = []

    // MARK: - Public Request

    func request<T: Decodable>(_ urlRequest: URLRequest,
                                type: T.Type) -> AnyPublisher<T, Error> {

        var request = urlRequest

        if let token = TokenStorage.shared.getAccessToken() {
            request.setValue("Bearer \(token)", forHTTPHeaderField: "Authorization")
        }

        return session.dataTaskPublisher(for: request)
            .tryMap { data, response in

                if let http = response as? HTTPURLResponse,
                   http.statusCode == 401 {
                    throw AuthError.unauthorized
                }

                return data
            }
            .decode(type: T.self, decoder: JSONDecoder())
            .catch { [weak self] error -> AnyPublisher<T, Error> in

                guard let self,
                      case AuthError.unauthorized = error else {
                    return Fail(error: error).eraseToAnyPublisher()
                }

                return self.handle401AndRetry(request, type: type)
            }
            .eraseToAnyPublisher()
    }
}

🔄 4. Handle 401 + Retry Logic (Combine Power)


extension APIClient {

    private func handle401AndRetry<T: Decodable>(
        _ request: URLRequest,
        type: T.Type
    ) -> AnyPublisher<T, Error> {

        // Prevent multiple refresh calls
        if isRefreshing {
            return Future { promise in
                self.pendingRequests.append { success in
                    if success {
                        self.request(request, type: type)
                            .sink(receiveCompletion: { completion in
                                if case let .failure(error) = completion {
                                    promise(.failure(error))
                                }
                            }, receiveValue: { value in
                                promise(.success(value))
                            })
                            .store(in: &self.cancellables)
                    } else {
                        promise(.failure(AuthError.sessionExpired))
                    }
                }
            }
            .eraseToAnyPublisher()
        }

        isRefreshing = true

        return AuthService.shared.refreshToken()
            .flatMap { _ -> AnyPublisher<T, Error> in
                return self.request(request, type: type)
            }
            .handleEvents(receiveCompletion: { [weak self] _ in
                guard let self else { return }
                self.isRefreshing = false
            }, receiveOutput: { _ in
                self.pendingRequests.forEach { $0(true) }
                self.pendingRequests.removeAll()
            })
            .catch { [weak self] error in
                self?.pendingRequests.forEach { $0(false) }
                self?.pendingRequests.removeAll()
                return Fail(error: error).eraseToAnyPublisher()
            }
            .eraseToAnyPublisher()
    }
}

🧪 Usage Example (ViewModel)


final class ProfileViewModel: ObservableObject {

    private var cancellables = Set()

    func fetchProfile() {

        let request = URLRequest(url: URL(string: "https://api.yourapp.com/profile")!)

        APIClient.shared.request(request, type: Profile.self)
            .receive(on: DispatchQueue.main)
            .sink(
                receiveCompletion: { completion in
                    if case let .failure(error) = completion {
                        print("Error:", error)
                    }
                },
                receiveValue: { profile in
                    print("Profile:", profile)
                }
            )
            .store(in: &cancellables)
    }
}
