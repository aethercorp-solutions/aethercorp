$unwind

In MongoDB, { $unwind: '$ContactList' } is an aggregation pipeline stage that separates an array into individual documents, creating one document for each element in the array.

1. Example

Suppose your MongoDB document looks like this:


{
    _id: 1,
    user_email: "john@example.com",
    ContactList: [
        { name: "Alice", status: "due" },
        { name: "Bob", status: "overdue" },
        { name: "Charlie", status: "due" }
    ]
}

When you execute:


{
    $unwind: '$ContactList'
}

MongoDB transforms the single document into three separate documents.


BEFORE — 1 DOCUMENT
 
  user_email: john@example.com
  ContactList: [Alice, Bob, Charlie]
  
  $unwind: '$ContactList'

AFTER — 3 DOCUMENTS

    { 
        user_email: "john@example.com",
        ContactList: { name: "Alice", status: "due" } 
    }

    { 
        user_email: "john@example.com",
        ContactList: { name: "Bob", status: "overdue" } 
    }

    { 
        user_email: "john@example.com",
        ContactList: { name: "Charlie", status: "due" } 
    }

Notice that MongoDB preserves the other fields, such as user_email, while replacing the array with one individual element per document.

2. Why is $unwind useful?

It allows you to filter, sort, count, or process individual array elements.

For example, you could find only contacts whose status is due:


db.users.aggregate([
  { $unwind: '$ContactList' },
  {
    $match: {
      'ContactList.status': 'due'
    }
  }
])

The result contains Alice and Charlie, each as a separate document.

3. How this applies to your Castanet code

In your getDueContacts aggregation pipeline, if ContactList is an array of contacts, this stage allows MongoDB to process each contact individually.

For example, you could:

  1. Unwind ContactList to separate each contact.
  2. Filter contacts based on their due dates.
  3. Sort the matching contacts.
  4. Apply pagination using $skip and $limit.

Important: $unwind increases the number of pipeline documents when an array contains multiple elements. If the array is empty or missing, MongoDB normally drops that document unless you use preserveNullAndEmptyArrays: true.

In simple terms: $unwind converts an array of contacts into individual records so MongoDB can query each contact separately.
