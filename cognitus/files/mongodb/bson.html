BSON (Binary JSON)

BSON (Binary JSON) is a binary format used by MongoDB to store and represent documents. It is similar to JSON, but it encodes data in a binary format that supports additional data types, such as dates and binary data.

Since you're working with Node.js and MongoDB, you'll encounter BSON when storing and retrieving data through MongoDB.

1. JSON vs. BSON

For example, consider this JSON document:


{
  "name": "John",
  "age": 30,
  "isActive": true
}

MongoDB stores documents using BSON, which encodes the same information in a binary representation rather than plain text.

Feature JSON BSON
Format Text Binary
Readable by humans Yes Not directly
Data types Basic types Additional types, including Date and ObjectId
Common use APIs and data exchange MongoDB document storage
Size and speed Text-based encoding Designed for efficient encoding, decoding, and database operations

BSON isn't necessarily smaller or faster than JSON in every situation; the result depends on the data and operation.

2. How BSON works in MongoDB

Consider a MongoDB document:


{
  _id: ObjectId("671a1234567890abcdef1234"),
  name: "John",
  age: 30,
  createdAt: new Date()
}

Here are three important BSON types:

  • ObjectId — A commonly used unique identifier for MongoDB documents.
  • Date — Stores a date and time as a BSON date value.
  • Int32 / Int64 — Represent integer values using specific numeric types.

These types go beyond standard JSON's basic data types.

3. How you use BSON with Node.js

When using the MongoDB Node.js driver, you usually don't need to convert objects to BSON manually. The driver handles serialization and deserialization.


const { MongoClient, ObjectId } = require("mongodb");

async function main() {
  const client = new MongoClient(process.env.MONGODB_URI);

  try {
    await client.connect();

    const db = client.db("myapp");
    const users = db.collection("users");

    // Insert a document
    const result = await users.insertOne({
      name: "John",
      age: 30,
      createdAt: new Date()
    });

    // Retrieve the document
    const user = await users.findOne({
      _id: new ObjectId(result.insertedId)
    });

    console.log(user);
  } finally {
    await client.close();
  }
}

main().catch(console.error);

The MongoDB driver converts JavaScript values into BSON when sending data to MongoDB and converts returned BSON documents back into JavaScript objects.

4. What about Mongoose?

If your Node.js application uses Mongoose, as many applications do, you still work primarily with JavaScript objects and Mongoose models.


const userSchema = new mongoose.Schema({
  name: String,
  age: Number,
  createdAt: Date
});

const User = mongoose.model("User", userSchema);

await User.create({
  name: "John",
  age: 30,
  createdAt: new Date()
});

Mongoose works with the MongoDB driver, which handles BSON serialization. Mongoose schemas define application-level data structure and validation, while BSON defines how document data is encoded for MongoDB.

The key takeaway: JSON is commonly used to exchange data between your frontend and backend, while BSON is the binary document format MongoDB uses internally to store and transmit documents. You generally don't need to handle BSON directly unless you're working with advanced MongoDB features or low-level data serialization.
