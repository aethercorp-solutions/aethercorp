JSX and TSX, style and layout

In JSX and TSX, style and layout are different concepts.

1. Style

Style controls how something looks.

Examples:

  • Text color
  • Font size
  • Background color
  • Border
  • Padding
  • Margin

JSX (.jsx)


function App() {
    return (
        <h1 style={{ color: "blue", fontSize: "32px" }}>
            Hello World
        </h1>
    );
}
                  
export default App;

TSX (.tsx)

Exactly the same, but with TypeScript.


function App() {
    return (
        <h1 style={{ color: "blue", fontSize: "32px" }}>
        Hello World
        </h1>
    );
}
    
export default App;

You can also use CSS.


<h1 className="title">Hello</h1>
            

.title {
    color: blue;
    font-size: 32px;
}

2. Layout

Layout controls where things are positioned on the page.

Examples:

  • Horizontal alignment
  • Vertical alignment
  • Two columns
  • Three columns
  • Sidebar
  • Header
  • Footer
  • Grid of cards

The most common layout tools are Flexbox and CSS Grid.


function App() {
    return (
        <div
            style={{
                display: "flex",
                justifyContent: "space-between",
                alignItems: "center",
            }}
        >
        <button<Login</button>
        <button<Register</button>
        </div>
    );
}

Result:


+--------------------------------------+
| Login                     Register   |
+--------------------------------------+

Grid Example


function App() {
    return (
        <div
            style={{
                display: "grid",
                gridTemplateColumns: "1fr 1fr",
                gap: "20px",
            }}
        >
        <div>Card 1</div>
        <div>Card 2</div>
        <div>Card 3</div>
        <div>Card 4</div>
    </div>
    );
}
