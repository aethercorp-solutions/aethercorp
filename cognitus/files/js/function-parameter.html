function parameter

A function parameter and a closure are related but different concepts.

Function Parameter

A parameter is a variable that a function receives as input.


function greet(name) {
    console.log(`Hello, ${name}`);
}

greet("Paul");

Here:

  • greet is the function.
  • name is the parameter.
  • "Paul" is the argument passed to the parameter.

Think of a parameter as a placeholder for data.

Closure

A closure is a function that remembers variables from its outer scope, even after the outer function has finished executing.


function createCounter() {
    let count = 0;

    return function () {
        count++;
        return count;
    };
}

const counter = createCounter();

console.log(counter()); // 1
console.log(counter()); // 2
console.log(counter()); // 3

Here:

  • The inner function is a closure.
  • It remembers the count variable from createCounter().
  • Even after createCounter() finishes, count still exists because the closure keeps a reference to it.

Comparison

Function Parameter Closure
Input to a function Function that remembers outer variables
Receives data from caller Accesses data from surrounding scope
Exists only during function execution Can keep variables alive after outer function returns
Example: name in greet(name) Inner function in createCounter()

Example Together


function multiplyBy(factor) {  // factor = parameter
    return function(number) {  // closure
        return number * factor;
    };
}

const double = multiplyBy(2);

console.log(double(5)); // 10

In this example:

  • factor is a function parameter.
  • The returned function is a closure because it remembers factor.
  • Even after multiplyBy(2) has finished, the closure still knows that factor is 2.

Interview Answer

A parameter is an input variable passed into a function. A closure is a function that captures and remembers variables from its surrounding scope, allowing it to access them even after the outer function has returned. Parameters provide data to a function, while closures preserve data from their lexical environment.

A function as a parameter means you pass a function into another function, just like you pass a number or a string.

Simple Example


function greet(name) {
    console.log("Hello " + name);
}

function execute(fn) {
    fn("Paul");
}

execute(greet);

What Happens?

  1. greet is a function.
  2. execute accepts a parameter named fn.
  3. We pass greet into execute.
  4. Inside execute, fn("Paul") calls greet("Paul").

Output:


Hello Paul

Real-Life Analogy

Imagine a coffee shop:


makeCoffee(recipe)

The coffee shop doesn't know which recipe to use.

You can pass:


espressoRecipe

or


latteRecipe

as the parameter.

The function receives another function and executes it.

Common Example: Callback


function processData(callback) {
    console.log("Processing...");
    callback();
}

processData(function() {
    console.log("Done!");
});

Output:


Processing...
Done!

Here:

  • callback is a function parameter.
  • The anonymous function is passed into processData.
  • processData calls it later.

Why Use Functions as Parameters?

They allow you to customize behavior without changing the function.


function calculate(a, b, operation) {
    return operation(a, b);
}

function add(x, y) {
    return x + y;
}

function multiply(x, y) {
    return x * y;
}

console.log(calculate(2, 3, add));      // 5
console.log(calculate(2, 3, multiply)); // 6

calculate() stays the same, but the operation changes depending on the function passed in.

This concept is the foundation of callbacks, event handlers, Promises, Array methods (map, filter, reduce), and React hooks.
