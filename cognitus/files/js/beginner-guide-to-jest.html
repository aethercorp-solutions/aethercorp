Beginner Guide to Jest

Jest is a popular JavaScript testing framework created by Meta. It is commonly used to test applications built with JavaScript, Node.js, React, and React Native.

Why Use Jest?

  • Easy to set up
  • Fast test execution
  • Built-in assertions
  • Mocking support
  • Code coverage reports
  • Works well with React and Node.js

1. Install Jest

For a Node.js project:


npm install --save-dev jest

Add a test script to package.json:


{
    "scripts": {
        "test": "jest"
    }
}

Run tests:


npm test

2. Create Your First Function

math.js


function add(a, b) {
    return a + b;
}
    
module.exports = add;

3. Create Your First Test

math.test.js


const add = require('./math');

test('adds 2 + 3 to equal 5', () => {
  expect(add(2, 3)).toBe(5);
});

Run:


npm test

Output:


PASS ./math.test.js
✓ adds 2 + 3 to equal 5

4. Common Matchers

Equality


expect(2 + 2).toBe(4);

Objects


expect({ name: 'Paul' }).toEqual({
    name: 'Paul'
});

Truthy/Falsy


expect(true).toBeTruthy();
expect(false).toBeFalsy();

Null


expect(null).toBeNull();

Arrays


expect(['Node', 'React']).toContain('Node');

5. Testing Async Functions

Promise Example


function fetchUser() {
    return Promise.resolve({
        id: 1,
        name: 'Paul'
    });
}
    
test('returns user', async () => {
    const user = await fetchUser();

    expect(user.name).toBe('Paul');
});

6. Using describe()

Group related tests:


describe('Math Functions', () => {
    test('add numbers', () => {
        expect(2 + 3).toBe(5);
    });
    
    test('subtract numbers', () => {
        expect(5 - 2).toBe(3);
    });
});

7. Setup and Cleanup


beforeEach(() => {
    console.log('Runs before each test');
});

afterEach(() => {
    console.log('Runs after each test');
});

Other hooks:


beforeAll(() => {});
afterAll(() => {});

8. Mock Functions


const mockFn = jest.fn();

mockFn('hello');

expect(mockFn).toHaveBeenCalled();
expect(mockFn).toHaveBeenCalledWith('hello');

9. Mocking Modules


// api.js
module.exports = {
  getUser: () => ({
    id: 1,
    name: 'Paul'
  })
};
            

jest.mock('./api');

const api = require('./api');

api.getUser.mockReturnValue({
  id: 99,
  name: 'Mock User'
});

test('returns mocked user', () => {
  expect(api.getUser().name).toBe('Mock User');
});

npx jest --coverage

Jest Interview Questions

What is Jest?

A JavaScript testing framework used for unit testing, integration testing, mocking, and coverage reporting.

Difference between toBe() and toEqual()?


expect(5).toBe(5);

toBe() uses strict equality (===).


expect({a:1}).toEqual({a:1});

toEqual() compares object contents recursively.

What is Mocking?

Replacing real dependencies with fake implementations during testing.

What is a Test Suite?

A collection of related test cases grouped using describe().

What is Code Coverage?

A metric showing how much of your code is executed by tests.

Example for a Senior Node.js Developer

Testing an Express service:


const userService = require('./userService');

describe('User Service', () => {
  test('creates user', async () => {
    const user = await userService.create({
      name: 'Paul'
    });

    expect(user.id).toBeDefined();
    expect(user.name).toBe('Paul');
  });
});

Learning Path

  1. Basic assertions (expect, toBe, toEqual)
  2. Test organization (describe, beforeEach)
  3. Async testing
  4. Mock functions (jest.fn)
  5. Mock modules (jest.mock)
  6. API testing with SuperTest
  7. React/React Native testing with React Testing Library
  8. Coverage reports and CI/CD integration

For a Node.js backend interview, focus heavily on async testing, mocking database calls, API endpoint testing, and testing error handling, as these are frequently discussed in senior-level interviews.
