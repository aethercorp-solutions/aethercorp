JavaScript functional programming

JavaScript functional programming is a style of programming where you build programs by combining small functions that transform data instead of changing it.

Think of it like a factory assembly line:


Raw Data -> Function A -> Function B -> Function C -> Result

Instead of writing lots of loops and changing variables, you pass data through functions.

Example

Traditional way


const numbers = [1, 2, 3, 4, 5];

let result = [];

for (let i = 0; i < numbers.length; i++) {
  result.push(numbers[i] * 2);
}

console.log(result);

Output:


[2, 4, 6, 8, 10]

Functional way


const numbers = [1, 2, 3, 4, 5];

const result = numbers.map(x => x * 2);

console.log(result);

Same result, less code.

Three Most Important Functions

1. map()

Transforms each item.


const names = ["Paul", "John", "Mary"];

const upper = names.map(name => name.toUpperCase());

console.log(upper);

Output:


["PAUL", "JOHN", "MARY"]

2. filter()

Keeps items that match a condition.


const numbers = [1, 2, 3, 4, 5];

const evens = numbers.filter(x => x % 2 === 0);

console.log(evens);

Output:


[2, 4]

3. reduce()

Combines items into one value.


const numbers = [1, 2, 3, 4, 5];

const sum = numbers.reduce(
  (total, current) => total + current,
  0
);

console.log(sum);

Output:


15

Chaining Functions

Functional programming becomes powerful when you combine functions.


const numbers = [1, 2, 3, 4, 5, 6];

const result = numbers
  .filter(x => x % 2 === 0)
  .map(x => x * 10)
  .reduce((sum, x) => sum + x, 0);

console.log(result);

Step by step:


[1,2,3,4,5,6]
      ↓ filter
[2,4,6]
      ↓ map
[20,40,60]
      ↓ reduce
120

Pure Functions

A pure function:

  • Same input → same output
  • Doesn't change outside variables

Good:


function add(a, b) {
    return a + b;
}

Bad:


let total = 0;

function addToTotal(x) {
  total += x;
}

The second function changes external state.

Immutability

Don't modify existing data.

Bad:


const arr = [1, 2, 3];

arr.push(4);

Good:


const arr = [1, 2, 3];

const newArr = [...arr, 4];

Output:


[1,2,3,4]

Original array stays unchanged.

Real React Native Example

Suppose you have contacts:


const contacts = [
  { name: "Paul", favorite: true },
  { name: "John", favorite: false },
  { name: "Mary", favorite: true }
];

Get favorite contact names:


const favoriteNames = contacts
  .filter(contact => contact.favorite)
  .map(contact => contact.name);

console.log(favoriteNames);

Output:


["Paul", "Mary"]

The Core Idea

Functional programming is mainly:

  1. Use functions as building blocks
  2. Avoid changing data
  3. Use map, filter, and reduce
  4. Create small reusable functions
  5. Transform data through pipelines
