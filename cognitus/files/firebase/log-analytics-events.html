Log Analytics Events

Yes. In React Native, you can use Firebase Analytics to log events, but you cannot retrieve raw analytics data directly from the Firebase Analytics SDK.

There are three common ways to work with Firebase Analytics:

1. Log Analytics Events (React Native SDK)

This is what most apps do.

Install


npm install @react-native-firebase/app
npm install @react-native-firebase/analytics

Initialize


import analytics from '@react-native-firebase/analytics';

Log a custom event


await analytics().logEvent('button_click', {
    screen: 'Home',
    button_name: 'Login'
});

Log screen views


await analytics().logScreenView({
    screen_name: 'Home',
    screen_class: 'HomeScreen',
});

Log user login


await analytics().logLogin({
    method: 'email'
});

Set User ID


await analytics().setUserId('user123');

Set User Properties


await analytics().setUserProperties({
    subscription: 'premium',
    country: 'PH'
});

2. Retrieve Analytics Data (No SDK API)

The Firebase SDK cannot do this:


const data = analytics().getEvents(); // ❌ Doesn't exist

Firebase Analytics is designed to send events, not read them.

Instead, analytics data is viewed in:

  • Firebase Console
  • Google Analytics (GA4)
  • BigQuery export

3. Retrieve Analytics Programmatically (Google Analytics Data API)

If you need analytics inside your own dashboard or backend, use the Google Analytics Data API.

Architecture:


React Native App
      │
      ▼
Firebase Analytics
      │
      ▼
Google Analytics 4
      │
      ▼
Google Analytics Data API
      │
      ▼
Your Backend
      │
      ▼
React Native App

Example (Node.js):


const {BetaAnalyticsDataClient} =
require('@google-analytics/data');

const client = new BetaAnalyticsDataClient();

const [response] = await client.runReport({
  property: 'properties/123456789',
  dimensions: [
    { name: 'eventName' }
  ],
  metrics: [
    { name: 'eventCount' }
  ],
    dateRanges: [
    {
      startDate: '7daysAgo',
      endDate: 'today'
    }
  ]
});

console.log(response);

Example response:


{
    "rows": [
        {
        "dimensionValues": [
            { "value": "button_click" }
        ],
        "metricValues": [
            { "value": "2345" }
        ]
        }
    ]
}

4. Export to BigQuery (Best for AI and Advanced Analytics)

Firebase can automatically export Analytics events to BigQuery.

Then you can run SQL queries like:


SELECT
  event_name,
  COUNT(*) AS total
FROM
  `project.analytics_123456.events_*`
GROUP BY
  event_name
ORDER BY
  total DESC;

This is ideal for:

  • User behavior analysis
  • Funnel analysis
  • Cohort analysis
  • Retention
  • AI/ML models
  • Recommendation systems

You can track nearly any user interaction.


analytics().logEvent('view_product', {

analytics().logEvent('purchase', {

Can AI Use Firebase Analytics?

Yes. A common architecture is:


User
   │
   ▼
React Native App
   │
   ▼
Firebase Analytics
   │
   ▼
BigQuery
   │
   ▼
Python / TensorFlow / AI Models
   │
   ▼
Insights

AI models can analyze data such as:

  • Most-used app features
  • User churn prediction
  • Session duration
  • Popular navigation paths
  • Purchase likelihood
  • Notification effectiveness
  • User segmentation

For example, if analytics shows that users who complete onboarding and view three products are much more likely to subscribe, an AI model can identify similar users and trigger personalized recommendations or reminders.

Summary

Task Supported? How
Log analytics events ✅ @react-native-firebase/analytics
View dashboards ✅ Firebase Console / Google Analytics 4
Retrieve analytics in code ✅ Google Analytics Data API (typically from your backend)
Export raw events ✅ BigQuery export
Build AI on analytics data ✅ BigQuery + Python/TensorFlow or other ML frameworks

If you're building a React Native app with an AI assistant or recommendation engine, the most scalable approach is:

React Native → Firebase Analytics → GA4 → BigQuery → Backend (Node.js/Python) → AI/ML → React Native

This keeps event collection lightweight on the device while enabling powerful analytics and AI processing on the backend.
