GA4 (Google Analytics 4)

GA4 (Google Analytics 4) is Google's latest analytics platform. It helps you understand how people use your website or mobile app by collecting and analyzing user interactions.

Think of it like this:

  • Firebase Analytics is what your app uses to send events.
  • GA4 is where those events are stored, analyzed, and reported.

For mobile apps, Firebase Analytics and GA4 are tightly integrated. When you enable Analytics in Firebase, your data is available in GA4.

Simple analogy

Imagine you own a supermarket.

  • Your cashier records every purchase → Firebase Analytics
  • The accounting office organizes all the receipts → GA4
  • The manager reviews sales reports to make decisions → You

Your app records events such as:


User opened app
User logged in
User searched
User viewed product
User purchased

Firebase sends those events to GA4, which turns them into reports and insights.

What GA4 records

Everything is based on events.

User action Event
Opens the app app_open
Logs in login
Views a product view_item
Searches search
Makes a purchase purchase
Shares content share

You can also create your own custom events:


analytics().logEvent('favorite_contact', {
    contact_id: '123',
});

That event appears in GA4 after it's processed.

Real example for a React Native app

Suppose you have a contact management app.

You log events like:


analytics().logEvent('contact_created');
            

analytics().logEvent('contact_deleted');
            

analytics().logEvent('contact_scheduled');
            

analytics().logEvent('premium_purchase');

After a week, GA4 might show:

Event Count
contact_created 12,430
contact_scheduled 8,102
premium_purchase 126

This helps you understand how people are actually using your app.

Can you access GA4 data programmatically?

Yes. Google provides the Google Analytics Data API, which lets your backend request reports from GA4.

  • Total active users
  • Most popular events
  • Purchases this month
  • Average session duration
  • Top countries
  • Device types

Why BigQuery matters

GA4 dashboards are excellent for reporting, but if you want to perform advanced analysis or train AI models, you can export all analytics events to BigQuery.

That lets you answer questions like:

  • Which users are likely to subscribe?
  • Which onboarding path leads to the highest retention?
  • What features do long-term users use most?
  • Which users are at risk of becoming inactive?

These analyses are difficult to do in standard GA4 reports but become straightforward with SQL and machine learning tools.

Funnels ❌ ✅
Audience creation ❌ ✅
Data API ❌ ✅
BigQuery export Configured through Firebase/GA4 ✅
AI and advanced analytics Via exported data Via BigQuery export

In short

  • Firebase Analytics is the SDK in your React Native app that records user actions.
  • GA4 (Google Analytics 4) is the analytics platform that receives those events and provides reports, dashboards, audience segmentation, funnels, and APIs.
  • For most mobile apps, you'll use Firebase Analytics to send data and GA4 to analyze it. If you need custom dashboards or AI-powered insights, you can access the data through the Google Analytics Data API or export it to BigQuery.
