union type

A union type in programming means:

A variable can hold one of several specified types or values.

It is basically an “OR” type.

TypeScript example

This is a union type:


type ContactFilter =
  "" |
  "all" |
  "due" |
  "overdue" |
  "unscheduled" |
  "upcoming" |
  "archived";

It means ContactFilter can be one of those exact values.


let filter: ContactFilter;

filter = "all";       // ✅
filter = "overdue";   // ✅
filter = "upcoming";  // ✅

filter = "random";    // ❌ Error

You can think of it as:


ContactFilter =
    "" OR
    "all" OR
    "due" OR
    "overdue" OR
    "unscheduled" OR
    "upcoming" OR
    "archived"

Union of different types

It doesn't have to be strings.


let id: string | number;

id = "ABC123";  // ✅
id = 123;       // ✅

id = true;      // ❌

Here:


string | number

means:

id can be a string OR a number.

Why use union types?

They make your code safer by restricting what values are allowed.

Without a union:


let filter: string;

filter = "overdue";
filter = "something-wrong";
filter = "banana";

With a union:


let filter: ContactFilter;

filter = "overdue"; // ✅
filter = "banana";  // ❌

So your ContactFilter from your Castanet code is actually a good example of a string literal union type.

Simple definition:

Union type = a type that allows a value to be one of multiple possible types/values.
