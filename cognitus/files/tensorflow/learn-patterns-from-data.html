Learn patterns from data

Think of TensorFlow as a toolkit that helps a computer learn patterns from data.

Simple example: predicting house prices

Suppose you give TensorFlow data like:

Size Bedrooms Price
50 m² 1 ₱2M
80 m² 2 ₱3M
120 m² 3 ₱5M

You want the computer to learn:

House features → Price

1. You give TensorFlow data


X = [[50, 1],
     [80, 2],
     [120, 3]]

y = [2, 3, 5]

X contains the inputs/features.

y contains the answers TensorFlow should learn.

2. TensorFlow creates a neural network

A very simple network looks like:


House Size ──────┐
    ├──> Neural Network ──> Predicted Price
Bedrooms ────────┘

Inside the network are weights.


Size × weight₁
Bedrooms × weight₂
       ↓
    calculation
       ↓
   prediction

The weights determine how important each input is.

3. It makes a prediction

Initially, the weights are basically guesses.

For example:


Actual price:     ₱5M
Predicted price:  ₱3M

That's a big error.

TensorFlow calculates this error using a loss function.


Prediction
    ↓
Compare with actual answer
    ↓
Loss / Error

4. TensorFlow adjusts the weights

This is the important part.

TensorFlow uses backpropagation + gradient descent to figure out:

"Which weights should I change, and by how much, to reduce the error?"

For example:


Before:

Size weight     = 0.20
Bedroom weight  = 0.10
Error            = HIGH

        ↓ training

After:

Size weight     = 0.35
Bedroom weight  = 0.18
Error            = LOWER

It repeats this process thousands or millions of times.


Data
 ↓
Prediction
 ↓
Calculate error
 ↓
Adjust weights
 ↓
Prediction
 ↓
Calculate error
 ↓
Adjust weights
 ↓
...

This repeated process is called training.

5. Eventually it learns the pattern

After training, you can give it a new house:


Size:       100 m²
Bedrooms:   2

TensorFlow might predict:


₱3.8M

The important thing is that you didn't explicitly program:


IF size > 90 AND bedrooms == 2
THEN price = ₱3.8M

Instead, the neural network learned the relationship from examples.

What is a "Tensor"?

This is where the name TensorFlow comes from.

A tensor is basically a way of storing numbers.

You can think of it as:


Scalar
  5

Vector
  [5, 10, 15]

Matrix
  [5, 10]
  [15, 20]

3D Tensor
  [
    [1, 2],
    [3, 4],

    [5, 6],
    [7, 8]
  ]

Neural networks process huge amounts of these numerical structures.

TensorFlow = tensors flowing through a computational graph/neural network.

How this applies to images

Suppose TensorFlow learns to recognize cats.

An image can be represented as numbers:


Image
 ↓
Pixels
 ↓
Numbers
 ↓
TensorFlow neural network
 ↓
Features
 ↓
Prediction

          Cat: 97%
          Dog:  2%
          Bird: 1%

The network gradually learns things such as:


pixels
  ↓
edges
  ↓
shapes
  ↓
eyes / ears / fur patterns
  ↓
cat

You don't manually program those features. The network learns them during training.

TensorFlow vs a normal program

Traditional programming


Rules + Data
     ↓
  Program
     ↓
  Answer

You tell the computer the rules.

Machine learning


Data + Answers
      ↓
   TensorFlow
      ↓
 Learned Model
      ↓
 New Data
      ↓
   Prediction

The computer learns the rules/patterns.

In one sentence

TensorFlow is a framework that lets you build and train neural networks by repeatedly making predictions, measuring errors, and adjusting the network's weights until it learns useful patterns from data.
