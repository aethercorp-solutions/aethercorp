Keras

Think of Keras as building a neural network by connecting simple building blocks.

1. What is a Tensor?

A tensor is simply data arranged in numbers.

You already know a normal variable:


age = 41

That's basically a single number — a scalar.

A list:


ages = [20, 30, 41, 50]

is a 1-dimensional tensor.

A table:


20  170  70
30  165  60
41  175  90
50  180  85

is a 2-dimensional tensor.

You can think of tensors like this:


Scalar        → 5

Vector        → [5, 10, 15]

Matrix        → [[5, 10],
                  [15, 20]]

Higher tensor → images, videos, batches of images, etc.

Example: an image

A color image might be:


Height × Width × Channels

224 × 224 × 3

The 3 represents:


Red
Green
Blue

So an image is essentially a tensor containing thousands of numbers.

2. What is a Layer?

A layer is something that transforms a tensor into another tensor.

Think:


INPUT
  ↓
[ Layer ]
  ↓
OUTPUT

For example:


[1, 2, 3]
     ↓
  Dense Layer
     ↓
[0.7, 0.2]

The layer takes numbers in and produces new numbers.

3. Why does a layer transform the numbers?

Because the layer has weights.

For a simple neural network:


input
  ↓
x weights
  ↓
calculation
  ↓
output

For example:


input = 10

weight = 0.5

10 × 0.5 = 5

A real neural-network layer has many weights and biases.

Conceptually:


output = input × weight + bias

During training, Keras adjusts those weights so the network becomes better at its task.

4. Keras Example

Here's a very simple neural network:


import keras

model = keras.Sequential([
    keras.layers.Dense(10),
    keras.layers.Dense(1)
])

You can visualize it:


Input Tensor
     ↓
┌─────────────┐
│ Dense(10)   │
└─────────────┘
     ↓
Tensor with 10 values
     ↓
┌─────────────┐
│ Dense(1)    │
└─────────────┘
     ↓
One output

So:

Tensor = the data

Layer = the operation that processes the data

5. What does Dense(10) mean?

Dense is one of the most common Keras layers.


keras.layers.Dense(10)

means:

Create a fully connected layer that produces 10 output values.

For example:


Input:

[2, 5, 7]

       ↓

Dense(10)

       ↓

[0.2, 1.5, -0.3, 2.1, ...]
              ↑
         10 values

The layer has learned weights that determine how the input values affect those 10 outputs.

6. Layers can do different jobs

Keras has many types of layers.

Dense

Usually used for traditional neural networks:


Dense(128)

Think:

"Take these numbers and learn relationships between them."

ReLU

An activation function:


keras.layers.ReLU()

Very simply:


negative → 0
positive → unchanged

Example:


[-5, 2, -1, 7]

       ↓ ReLU

[0, 2, 0, 7]

Conv2D

Used heavily for images:


keras.layers.Conv2D(...)

Think:

"Look for patterns in the image."

Such as:


edges
corners
textures
shapes
objects

Flatten

Turns a multidimensional tensor into one long vector.


Image

28 × 28

   ↓ Flatten

784 values

Dropout

Randomly turns off some connections during training.

Think:

"Don't let the network become too dependent on particular neurons."

7. Putting layers together

This is where neural networks become interesting.

Imagine:


model = keras.Sequential([
    keras.layers.Dense(128, activation="relu"),
    keras.layers.Dense(64, activation="relu"),
    keras.layers.Dense(10, activation="softmax")
])

Think of it as:


INPUT
  │
  ▼
┌──────────────┐
│ Dense 128    │
│ ReLU         │
└──────────────┘
  │
  ▼
128 numbers
  │
  ▼
┌──────────────┐
│ Dense 64     │
│ ReLU         │
└──────────────┘
  │
  ▼
64 numbers
  │
  ▼
┌──────────────┐
│ Dense 10     │
│ Softmax      │
└──────────────┘
  │
  ▼
10 probabilities

Each layer transforms the tensor.

8. The easiest way to remember it

Think of a factory.


RAW MATERIAL
     │
     ▼
┌───────────┐
│ Machine 1 │  ← Layer
└───────────┘
     │
     ▼
┌───────────┐
│ Machine 2 │  ← Layer
└───────────┘
     │
     ▼
┌───────────┐
│ Machine 3 │  ← Layer
└───────────┘
     │
     ▼
PRODUCT

The material moving through the factory is the tensor.

The machines processing it are the layers.

So:


Tensor = data

Layer = data transformation

Model = collection of layers

Training = adjusting layer weights

Prediction = passing tensors through the layers

9. One complete mental model

When you start learning Keras, keep this picture in your head:


                NEURAL NETWORK

                Input Data
                   │
                   │  Tensor
                   ▼
                ┌─────────────┐
                │   Layer 1   │
                └─────────────┘
                   │
                   │  Tensor
                   ▼
                ┌─────────────┐
                │   Layer 2   │
                └─────────────┘
                   │
                   │  Tensor
                   ▼
                ┌─────────────┐
                │   Layer 3   │
                └─────────────┘
                   │
                   ▼
                Prediction

Keras is essentially giving you an easy way to build and train this pipeline.

If you're learning Keras from scratch, the next important concept after tensors → layers is neurons → weights → activation functions → loss → optimizer → training.
