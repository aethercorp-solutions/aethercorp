TensorFlow Hands-on Tutorial (Beginner to Intermediate)

Since you've asked before about TensorFlow and Firebase Analytics, I'll teach TensorFlow from the ground up with a hands-on project. By the end, you'll have trained your own AI model and understand how machine learning works in practice.

What you'll build

You'll create an AI model that predicts the price of a house based on its size.

Example dataset:

Size (sq ft) Price ($)
500 120000
800 180000
1000 230000
1200 275000
1500 340000
1800 390000
2000 430000

Eventually you'll ask:

"If a house is 1700 sq ft, what should its price be?"

TensorFlow will predict it.

Download

https://python.org

python3 --version

Step 4 Install Extra Libraries

These libraries are commonly used alongside TensorFlow:

  • NumPy → math
  • Pandas → datasets
  • Matplotlib → graphs
  • Scikit-learn → preprocessing and evaluation

Step 5 Create Your First Tensor

Create


import tensorflow as tf

x = tf.constant([1,2,3])

print(x)

Output


tf.Tensor([1 2 3], shape=(3,), dtype=int32)

TensorFlow stores data as tensors, which are like multidimensional arrays.

Step 6 Tensor Math


a = tf.constant([1,2,3])
b = tf.constant([4,5,6])

print(a+b)

Output


[5 7 9]

Multiplication


print(a*b)

Output


[4 10 18]

Step 7 Create Training Data


import numpy as np

house_size = np.array([
500,
800,
1000,
1200,
1500,
1800,
2000
])

house_price = np.array([
120000,
180000,
230000,
275000,
340000,
390000,
430000
])

This is your dataset.

Step 8 Normalize Data

Machine learning performs better when values are on a similar scale.


house_size = house_size / 2000
house_price = house_price / 500000

Step 9 Build Your First Model


model = tf.keras.Sequential([
    tf.keras.layers.Dense(units=1)
])

This means:


Input

↓

Neuron

↓

Output

Step 10 Compile the Model


model.compile(
    optimizer='adam',
    loss='mean_squared_error'
)

Optimizer


Adam

helps the model learn efficiently.

Loss


Mean Squared Error

measures prediction error.

Step 11 Train the Model


model.fit(
    house_size,
    house_price,
    epochs=500
)

You'll see output like


Epoch 1

loss=0.24

Epoch 50

loss=0.03

Epoch 500

loss=0.0004

Notice the loss decreases as the model learns.

Step 12 Make a Prediction

Predict the price of a 1700 sq ft house.

Normalize the input first:


prediction = model.predict([1700/2000])

print(prediction)

Example


0.76

Convert back to dollars:


print(prediction*500000)

Output


380000

Step 13 Visualize the Data


import matplotlib.pyplot as plt

plt.scatter(house_size*2000, house_price*500000)
plt.xlabel("Size")
plt.ylabel("Price")
plt.show()

Step 14 Save the Model


model.save("house_model.keras")

Step 15 Load the Model


new_model = tf.keras.models.load_model("house_model.keras")

Predict again


new_model.predict([1700/2000])

Understanding What Happened

The model learns a function:


House Size

↓

Weights

↓

Bias

↓

Predicted Price

During training, TensorFlow adjusts the weights and bias to reduce prediction errors.

Step 17 Add More Layers (Deep Learning)


model = tf.keras.Sequential([
    tf.keras.layers.Dense(32, activation='relu'),
    tf.keras.layers.Dense(16, activation='relu'),
    tf.keras.layers.Dense(1)
])

This is a simple neural network:


Input

↓

Hidden layers allow the model to learn more complex relationships.

Step 18 Evaluate


loss = model.evaluate(X, y)

print(loss)

Step 19 Predict New Data

Next Hands-on Projects

This sequence builds practical skills that translate directly to real-world business applications.
