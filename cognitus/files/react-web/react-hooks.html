React Hooks

React Hooks are special functions that let you use React features (like state, lifecycle, and context) inside function components. Before Hooks, these features were only available in class components.

Think of a Hook as a tool that React gives your component.

  • useState → remembers data
  • useEffect → runs code after rendering
  • useRef → stores a value without causing a re-render
  • useContext → shares data across components
  • Custom hooks → reuse logic between components

1. useState - Store Data

Imagine you have a counter.


import { useState } from "react";

export default function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
        <h1>{count}</h1>

        <button onClick={() => setCount(count + 1)}>
            Add
        </button>
    </div>
  );
}

How it works


const [count, setCount] = useState(0);

React gives you two things:


count      -> current value
setCount() -> changes the value

Initially

After clicking the button


setCount(1)

React updates the UI automatically.

2. useEffect - Run Code After Rendering

Suppose you want to print something every time the page loads.


import { useEffect } from "react";

function Home() {

  useEffect(() => {
    console.log("Page Loaded");
  }, []);

  return <h1>Home</h1>
}

The empty dependency array ([]) means the effect runs only once when the component first mounts.

Another example:


useEffect(() => {
    console.log("Count changed");
}, [count]);

Now it runs every time count changes.

3. useRef - Remember Something Without Re-rendering

Suppose you have an input.


import { useRef } from "react";

function Login() {
  const inputRef = useRef<HTMLInputElement>(null);

  return (
    <>
        <input ref={inputRef} />

        <button
            onClick={() => inputRef.current?.focus()}
        >
        Focus
        </button>
    </>
  );
}

When you click the button:


inputRef
      ↓
<input>

React focuses the input.

Unlike useState, changing useRef.current does not cause the component to re-render.

4. useContext - Share Data

Instead of passing props through many components, use Context.


App
 │
 ├── Header
 │
 ├── Sidebar
 │
 └── Dashboard

Suppose all components need the logged-in user.

Without Context:


App
 ↓
Header
 ↓
Sidebar
 ↓
Dashboard

You keep passing props.

With Context:


User Context

       ↑
Header
Sidebar
Dashboard

Everyone can access the same shared data.
