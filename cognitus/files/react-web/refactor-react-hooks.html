Refactor React hooks

A good way to refactor React hooks is to move all state management and business logic into a custom hook, while keeping the component responsible only for rendering the UI.

Before (everything inside the component)


"use client";

import { useState } from "react";

export default function CounterPage() {
  const [count, setCount] = useState(0);

  const increment = () => {
    setCount((prev) => prev + 1);
  };

  const decrement = () => {
    setCount((prev) => prev - 1);
  };

  const reset = () => {
    setCount(0);
  };

  return (
    <div>
        <h1>{count}</h1>

        <button onClick={increment}>+</button>
        <button onClick={decrement}>-</button>
        <button onClick={reset}>Reset</button>
    </div>
  );
}

Step 1. Create a custom hook


hooks/
    useCounter.ts
            

import { useState } from "react";

export function useCounter(initialValue = 0) {
  const [count, setCount] = useState(initialValue);

  const increment = () => {
    setCount((prev) => prev + 1);
  };

  const decrement = () => {
    setCount((prev) => prev - 1);
  };

  const reset = () => {
    setCount(initialValue);
  };

  return {
    count,
    increment,
    decrement,
    reset,
  };
}

Step 2. Use the hook


"use client";

import { useCounter } from "@/hooks/useCounter";

export default function CounterPage() {
  const {
    count,
    increment,
    decrement,
    reset,
  } = useCounter();

  return (
    <div>
        <h1>{count}</h1>

        <button onClick={increment}>+</button>
        <button onClick={decrement}>-</button>
        <button onClick={reset}>Reset</button>
    </div>
  );
}

Now your component is only responsible for displaying the UI.

Real-world example (File Upload)

Suppose your page originally looks like this:


const [files, setFiles] = useState<File[]>([]);
const [loading, setLoading] = useState(false);
const [dragging, setDragging] = useState(false);

const onDrop = (files: FileList) => {
    ...
};

const upload = async () => {
    ...
};

const removeFile = (index: number) => {
    ...
};

Move all of that into a hook.


hooks/
    useUpload.ts
            

import { useState } from "react";

export function useUpload() {
  const [selectedFiles, setSelectedFiles] = useState<File[]>([]);
  const [loading, setLoading] = useState(false);
  const [dragging, setDragging] = useState(false);

  const addFiles = (files: FileList | File[]) => {
    const list = Array.from(files);
    setSelectedFiles((prev) => [...prev, ...list]);
  };

  const removeFile = (index: number) => {
    setSelectedFiles((prev) =>
      prev.filter((_, i) => i !== index)
    );
  };

  const upload = async () => {
    setLoading(true);

    try {
      // upload logic here
    } finally {
      setLoading(false);
    }
  };

  return {
    selectedFiles,
    loading,
    dragging,
    setDragging,
    addFiles,
    removeFile,
    upload,
  };
}

Then your page becomes much cleaner.


    "use client";
    
    import { useUpload } from "@/hooks/useUpload";

        const {

        <div>

    }

Even better architecture

As your application grows, separate responsibilities further:


Component
      │
      ▼
Custom Hook
      │
      ▼
Service/API
      │
      ▼
Backend

Example:

Component


const { upload } = useUpload();

useUpload.ts


const upload = async () => {
    setLoading(true);

    try {
        await uploadService.upload(selectedFiles);
    } finally {
        setLoading(false);
    }
};

uploadService.ts


import axios from "axios";

export const uploadService = {
  async upload(files: File[]) {
    const formData = new FormData();

    files.forEach((file) => {
      formData.append("files", file);
    });

    return axios.post("/api/upload", formData);
  },
};

This layered approach offers several benefits:

  • Components focus only on rendering the UI.
  • Custom hooks manage state and user interactions.
  • Services handle API requests and business logic.
  • Utilities contain reusable helper functions.
  • Types centralize TypeScript interfaces.

This pattern scales well in medium-to-large React and Next.js applications and keeps code easier to test, maintain, and reuse.
