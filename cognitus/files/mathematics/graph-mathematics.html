Graph theory

Graph theory is a branch of mathematics that studies graphs, which are structures used to represent objects and the relationships between them.

Simple Idea

Imagine a social network:

  • People = objects
  • Friendships = relationships

Graph theory models this as:


Alice ----- Bob
  |
  |
Charlie
  • Alice, Bob, Charlie are called vertices (nodes).
  • The lines connecting them are called edges.

Formal Definition

A graph is written as:


G=(V,E)

where:

  • G = graph
  • V = set of vertices (nodes)
  • E = set of edges (connections)

Example:


V = {A, B, C}

E = {{A,B}, {A,C}}

Meaning:

  • A is connected to B
  • A is connected to C

Graph:


                B
                |
                A
                |
                C

Why Graph Theory Exists

Many real-world systems are naturally networks:

Real World Vertex Edge
Facebook Person Friendship
Internet Computer Network connection
Road Map City Road
Airline Network Airport Flight route
AI Knowledge Graph Concept Relationship
Family Tree Person Parent-child relation

Two Main Types of Graphs

1. Undirected Graph

Relationships go both ways.


Alice ---- Bob

Friendship example:

If Alice is friends with Bob,

Bob is also friends with Alice.

Edge:


{Alice, Bob}

2. Directed Graph (Digraph)

Relationships have direction.


Alice ---> Bob

Example:

  • Alice follows Bob on social media.
  • Bob may not follow Alice.

Edge:


(Alice, Bob)

Example: Cities and Roads

Suppose:


Manila
   |
Quezon City
   |
Makati

Vertices:


V = {Manila, QuezonCity, Makati}

Edges:


E = {
    {Manila, QuezonCity},
    {QuezonCity, Makati}
}

Graph theory can answer:

  • Is Makati reachable from Manila?
  • What is the shortest route?
  • Which city is most connected?

Important Concepts

Path

A sequence of connected vertices.


A -> B -> C -> D

Path from A to D:


A, B, C, D

Degree

Number of connections a vertex has.


B
|
A---C
|
D

Degree of A = 3

Cycle

A path that returns to the starting vertex.


A --- B
|     |
D --- C

You can travel:


A → B → C → D → A

This is a cycle.

Why Graph Theory is Important in Computing

Graph theory is everywhere in computer science:

  • Search engines rank webpages using graphs.
  • GPS finds shortest paths using graph algorithms.
  • Social networks analyze relationships using graphs.
  • Compilers use dependency graphs.
  • AI uses knowledge graphs and graph neural networks.
  • Operating systems use process and resource graphs.

In One Sentence

Graph theory is the mathematical study of objects (vertices) and the relationships (edges) between them, allowing us to model and analyze networks, connections, and pathways in the real world and computing.
