Linear Equations

Neural networks use linear equations to combine information, then use a nonlinear activation function to make intelligent decisions.

Here's the idea in simple terms.

Step 1: Linear equation combines the inputs

Imagine you want a neural network to recognize whether a fruit is an apple.

The inputs are:

  • Weight = 150 g
  • Color = 8 (redness score)
  • Roundness = 9

The neuron first calculates:


y = w1 * x1 + w2 * x2 + w3 * x3 + b

where:

  • x = inputs
  • w = weights (how important each input is)
  • b = bias (an adjustment)

This is just a linear equation.

For example:


y=(0.01)(150)+(0.5)(8)+(0.4)(9)−2
y=1.5+4+3.6−2=7.1

The neuron has combined all the information into one number.

Step 2: Activation function decides what to do

The neuron then passes 7.1 into an activation function.

For example:

  • If the value is high → "Looks like an apple."
  • If the value is low → "Not an apple."

Without this step, every layer would only perform linear equations, and the network couldn't learn complex patterns.

Step 3: Thousands or millions of neurons repeat this

A neural network is simply many neurons connected together.

Each neuron performs:


Output = w1x1 + w2x2 + ... + b

followed by an activation function.


Inputs
  ↓
Linear Equation
  ↓
Activation Function
  ↓
Next Layer
  ↓
Linear Equation
  ↓
Activation Function
  ↓
Prediction

Real-world example: Handwritten digit recognition

Suppose you draw the number 5.

Each pixel becomes an input.


Pixel 1 = 0
Pixel 2 = 255
Pixel 3 = 120
...
Pixel 784 = 40

One neuron computes something like:


y = w1x1 + w2x2 + ... + w784*x784 + b

This linear equation summarizes all 784 pixel values into a single score.

Many neurons perform similar calculations, each looking for different features such as:

  • vertical lines,
  • curves,
  • loops,
  • corners.

Why linear equations are important

Linear equations are used because they:

  • Combine many input values into one result.
  • Let the network assign different importance (weights) to each input.
  • Are fast to compute, even millions of times.

However, linear equations alone are not enough. Neural networks also need activation functions to learn complex patterns like faces, speech, and language.

Simple analogy

Think of a teacher grading a student:

  • Homework × 20%
  • Quiz × 30%
  • Exam × 50%

The teacher computes:


Final Score=0.2(Homework)+0.3(Quiz)+0.5(Exam)

This is also a linear equation.

A neuron works in the same way:

  • Inputs = homework, quiz, exam
  • Weights = importance of each input
  • Output = weighted score

The only difference is that after computing the weighted score, the neuron applies an activation function to decide how strongly to pass that information to the next layer.

A nonlinear activation function is a function that changes the output in a way that is not a straight-line relationship. It gives neural networks the ability to learn complex patterns instead of only simple linear relationships.

Think of it like a light switch

A neuron first computes a linear equation:


y = w1 * x1 + w2 * x2 + b

Suppose the result is:

  • -3
  • 0
  • 5

Instead of sending these values directly to the next neuron, it passes them through an activation function.

For example, the ReLU (Rectified Linear Unit) activation function works like this:

  • If the value is negative → output 0
  • If the value is positive → keep it

Input    Output
 -3   →    0
  0   →    0
  5   →    5

This is nonlinear because the rule suddenly changes at 0—it isn't just one straight-line equation.

Why not use only linear equations?

Imagine two neural network layers.

Layer 1:


y=2x+1

Layer 2:


z=3y+4

Substitute the first equation into the second:


z=3(2x+1)+4
z=6x+7

Notice that two linear equations are still just one linear equation.

No matter how many linear layers you stack, they are equivalent to a single linear transformation. The network cannot learn complicated patterns.

What happens with a nonlinear activation?

Suppose the first layer computes:


y=2x+1

Then apply ReLU:


If y < 0 → 0
If y ≥ 0 → y

Now the second layer receives a value that has been changed by a nonlinear rule.

Example:

x Linear Output After ReLU
-2 -3 0
-1 -1 0
0 1 1
1 3 3
2 5 5

The output no longer follows one straight line. It becomes a piecewise function, allowing the network to represent much more complex relationships.

Real-world analogy

Imagine you're deciding whether to bring an umbrella.

A linear equation might calculate a score:


Score = (Chance of Rain × 0.7)
    + (Cloudiness × 0.3)

Suppose the score is 0.8.

Now apply a nonlinear rule:


If score > 0.5
    Bring an umbrella
Else
    Don't bring one

The decision changes suddenly at 0.5. That threshold is a nonlinear behavior.

Why is this important for AI?

Without nonlinear activation functions, a neural network could only learn simple patterns like:

  • House price increases with size.
  • Salary increases with years of experience.

With nonlinear activations, it can learn much more complex relationships, such as:

  • Recognizing faces from millions of pixels.
  • Understanding speech despite different accents.
  • Translating languages.
  • Detecting tumors in medical images.
  • Driving autonomous vehicles.

The key idea

A neural network works in two steps:

  1. Linear equation: Combine the inputs into a weighted sum.
  2. Nonlinear activation: Transform that result so the network can learn complex patterns.

Think of it this way:

  • Linear equation = "Calculate a score."
  • Nonlinear activation = "Decide how that score should influence the next step."

Both are essential. The linear equation gathers information, while the nonlinear activation gives the network the flexibility to solve real-world problems that aren't just straight-line relationships.
