Learn AWS effectively

To learn AWS effectively, don't try to memorize all AWS services. Learn what problem each service solves, then practice creating and connecting them using both the AWS Console and AWS CLI.

A simple path:

1. Understand AWS Basics First

AWS is basically a collection of building blocks:

Need AWS Service Simple Meaning
Run backend code Lambda Execute code without managing servers
Store files S3 Cloud file storage
Run servers EC2 Virtual machines
Database RDS / DynamoDB Store application data
API endpoint API Gateway Expose APIs to users
Permissions IAM Control who can access what
Networking VPC Private cloud network
Monitoring CloudWatch Logs and metrics
DNS Route 53 Domain management
Email SES Send emails

Think of AWS like building a house:


IAM        = Security guards
VPC        = Land
EC2       = Computer/server
Lambda    = Worker who runs tasks
S3        = Storage room
RDS       = Database
API GW    = Front door
CloudWatch = Security cameras

Learning Roadmap

Phase 1: Create an AWS Account and Learn IAM

Start here because everything depends on permissions.

Learn:

  • Users
  • Roles
  • Policies
  • Access keys
  • MFA

Console:


AWS Console
   |
   └── IAM
        |
        ├── Users
        ├── Roles
        └── Policies

Example:

Create a user:


DeveloperUser
     |
     └── AmazonS3FullAccess

Meaning:

"This developer can manage S3."

Phase 2: Install AWS CLI

Install:

https://aws.amazon.com/cli/

Check:


aws --version

Example:


aws-cli/2.15.0 Python/3

Configure:


aws configure

You enter:


AWS Access Key ID:
AWS Secret Access Key:
Default region:
Output format:

Example:


AWS Access Key ID: ABC123
AWS Secret Key: XYZ456
Region: us-east-2
Output: json

Test:


aws sts get-caller-identity

Result:


{
    "UserId": "AIDA123",
    "Account": "803303263828",
    "Arn": "arn:aws:iam::803303263828:user/developer"
}

Download:


aws s3 cp s3://my-first-test-bucket/photo.png .

Phase 7: Learn Databases

DynamoDB

AWS NoSQL database.

Example:

Users

id       name
----------------
1        Paul
2        John

CLI:

Create table:


aws dynamodb create-table \
--table-name Users \
--attribute-definitions AttributeName=id,AttributeType=S \
--key-schema AttributeName=id,KeyType=HASH \
--billing-mode PAY_PER_REQUEST
