Cloud-native applications

Cloud-native applications are software applications designed specifically to run in cloud environments such as AWS, Microsoft Azure, or Google Cloud. They are built to be scalable, resilient, easy to deploy, and easy to maintain.

Instead of building one large application that runs on a single server, cloud-native applications often use smaller services, managed cloud services, containers, and automated deployment pipelines.

1. Simple example

Imagine you're developing the Castanet contact management application.

1. Frontend

React web dashboard or React Native mobile app

2. API layer

Amazon API Gateway receives requests from the app.

3. Backend

Node.js functions on AWS Lambda handle business logic.

4. Database

MongoDB stores contacts, notes, and schedules.

When users add contacts, the backend processes their requests and saves the data. If usage increases, AWS Lambda can run more function instances automatically, subject to its configuration and service limits.

This is an example of a cloud-native architecture.
