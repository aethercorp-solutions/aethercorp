Market leaders

The three dominant hyperscalers are:

  1. Amazon Web Services — Largest cloud provider, strongest ecosystem, widely used by startups and enterprises.
  2. Microsoft Azure — Strongest in enterprise IT, Windows, .NET, and Microsoft 365 integration.
  3. Google Cloud — Strong in AI, machine learning, Kubernetes, and data analytics.

For your stack

Based on your recent work with serverless APIs, React, React Native, OAuth, and AI, the closest equivalents are:

  • AWS Lambda ↔ Azure Functions ↔ Google Cloud Functions
  • API Gateway ↔ Azure API Management ↔ Google API Gateway
  • Amazon Cognito ↔ Microsoft Entra ID ↔ Google Identity Platform
  • S3 ↔ Azure Blob Storage ↔ Google Cloud Storage
  • DynamoDB ↔ Azure Cosmos DB ↔ Firestore
  • ECS/EKS ↔ Azure Kubernetes Service (AKS) ↔ Google Kubernetes Engine (GKE)

These services are considered the standard equivalents across the three major cloud providers and are commonly used when designing portable cloud architectures.
