Uploading a PDF to AWS S3

Below is a common Node.js + AWS SDK v3 implementation (good for a Next.js / serverless backend).

Uploading a PDF to AWS S3 usually involves these steps:

  1. Create an S3 bucket
  2. Configure permissions (IAM)
  3. Upload the PDF from your backend/frontend
  4. Store the S3 URL or key in your database

1. Create an S3 Bucket

Go to:

AWS S3 Console

Create a bucket:

Example:


aether-research-publications

Recommended settings:

  • Block public access: keep ON (recommended)
  • Enable encryption: ON
  • Enable versioning: optional

2. Create IAM User Permission

Create an IAM policy:


{
    "Version": "2012-10-17",
    "Statement": [
        {
        "Effect": "Allow",
        "Action": [
            "s3:PutObject",
            "s3:GetObject",
            "s3:DeleteObject"
        ],
        "Resource": "arn:aws:s3:::aether-research-publications/*"
        }
    ]
}

Attach it to your backend IAM user or Lambda role.

3. Install AWS SDK

Node.js:


npm install @aws-sdk/client-s3

4. Configure AWS Client

Create:


lib/s3.ts
            

import { S3Client } from "@aws-sdk/client-s3";

export const s3 = new S3Client({
  region: process.env.AWS_REGION,
  credentials:{
    accessKeyId: process.env.AWS_ACCESS_KEY_ID!,
    secretAccessKey: process.env.AWS_SECRET_ACCESS_KEY!
  }
});

5. Upload PDF API (Next.js Example)

Example:


app/api/upload/route.ts
            

import { PutObjectCommand } from "@aws-sdk/client-s3";
import { s3 } from "@/lib/s3";


export async function POST(req:Request){

  const formData = await req.formData();

  const file = formData.get("file") as File;


  if(!file){
    return Response.json({
      error:"No file uploaded"
    },{
      status:400
    });
  }


  const buffer = Buffer.from(
    await file.arrayBuffer()
  );


  const fileName =
    `publications/${Date.now()}-${file.name}`;


  await s3.send(
    new PutObjectCommand({
      Bucket:process.env.AWS_BUCKET_NAME,
      Key:fileName,
      Body:buffer,
      ContentType:"application/pdf"
    })
  );


  return Response.json({
    success:true,
    key:fileName
  });

}

6. Frontend Upload Component

Example React:


"use client";

import {useState} from "react";


export default function UploadPDF(){

const [file,setFile]=useState<File|null>(null);


async function upload(){

 if(!file)return;


 const formData=new FormData();

 formData.append(
   "file",
   file
 );


 const res=await fetch(
   "/api/upload",
   {
    method:"POST",
    body:formData
   }
 );


 const data=await res.json();

 console.log(data);

}


return (

    <div>

    <input
        type="file"
        accept="application/pdf"
        onChange={(e)=>
            setFile(
            e.target.files?.[0] || null
        )
        }
    />


    <button
        onClick={upload}
        >
        Upload PDF
    </button>


    </div>

);

}

9. Generate Secure Download URL (Recommended)

Instead of making PDFs public, use a signed URL.

Install:


npm install @aws-sdk/s3-request-presigner

Example:


import {
    GetObjectCommand
} from "@aws-sdk/client-s3";
    
import {
    getSignedUrl
} from "@aws-sdk/s3-request-presigner";
    
    
const command =
    new GetObjectCommand({
        Bucket:"aether-research-publications",
        Key:"publications/paper.pdf"
});
    
    
const url =
    await getSignedUrl(
        s3,
        command,
        {
        expiresIn:3600
        }
);
    
    
console.log(url);

The user gets a temporary download link.
