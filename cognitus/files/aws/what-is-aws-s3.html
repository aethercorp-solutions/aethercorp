What is AWS S3?

AWS S3 (Simple Storage Service) is like a giant online hard drive in the cloud.

Instead of storing files on your server, you store them in S3.

Examples of files stored in S3:

  • User profile pictures
  • Documents (PDFs)
  • Videos
  • Audio files
  • Backups
  • App images

Simple Example

Imagine your React Native app lets users upload profile photos.

Without S3:


React Native App
      |
      v
Node.js Server
      |
      v
Server Hard Drive

Problem:

  • Server storage can run out
  • Difficult to scale
  • If server crashes, files may be lost

With S3:


React Native App
      |
      v
Node.js API (Lambda)
      |
      v
AWS S3 Bucket

Benefits:

  • Almost unlimited storage
  • Highly durable
  • Scales automatically
  • Cheap

Important Terms

Bucket

A bucket is like a folder at the top level.

Example:


Bucket: trycastanet-files

Inside:


trycastanet-files
├── users/
│   ├── photo1.jpg
│   └── photo2.jpg
├── documents/
│   └── contract.pdf

Object

Every file stored in S3 is called an Object.

Example:


users/photo1.jpg

How Upload Works

Step 1

User selects a photo.


React Native

Step 2

Photo is sent to your Node.js Lambda.

Step 3

Lambda uploads it to S3.

Step 4

S3 returns a URL.

Example:


https://mybucket.s3.amazonaws.com/users/photo1.jpg

Step 5

Save the URL in MongoDB.

Create S3 Bucket

  1. Login to AWS Console.
  2. Open Amazon Web Services S3.
  3. Click Create Bucket.
  4. Enter:

    trycastanet-files

  5. Create bucket.

Done.

Install SDK

Node.js:


npm install @aws-sdk/client-s3

Configure AWS Credentials

Lambda IAM Role needs:


{
    "Effect": "Allow",
    "Action": [
        "s3:PutObject",
        "s3:GetObject",
        "s3:DeleteObject"
    ],
    "Resource": "arn:aws:s3:::trycastanet-files/*"
}

This allows Lambda to upload files.

Upload File Example


const { S3Client, PutObjectCommand } =
require("@aws-sdk/client-s3");

const s3 = new S3Client({
  region: "ap-southeast-1"
});

async function uploadFile(buffer, fileName) {

  const command = new PutObjectCommand({
    Bucket: "trycastanet-files",
    Key: `users/${fileName}`,
    Body: buffer,
    ContentType: "image/jpeg"
  });

  await s3.send(command);

  return `https://trycastanet-files.s3.ap-southeast-1.amazonaws.com/users/${fileName}`;
}

Usage:


const url = await uploadFile(
  imageBuffer,
  "profile.jpg"
);

console.log(url);

Better Approach for React Native

Instead of:


Mobile → Lambda → S3

Use:


Mobile → Presigned URL
          ↓
          S3

Why?

Large files don't pass through Lambda.

Benefits:

  • Faster
  • Cheaper
  • Less Lambda memory usage

Presigned URL Flow

1. App asks Lambda


POST /upload-url

2. Lambda generates temporary upload URL

Example:


https://s3.amazonaws.com/...

3. React Native uploads directly to S3


fetch(uploadUrl, {
    method: "PUT",
    body: imageBlob
});

4. Save file URL in MongoDB

Done.
