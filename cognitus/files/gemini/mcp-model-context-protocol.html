MCP (Model Context Protocol)

MCP (Model Context Protocol) is basically a standard way for an AI model to use external tools and data.

Think of it like a USB standard for AI.

Without MCP

An AI agent might need custom code for every tool:


LLM
 ↓
Custom code
 ├── Gmail API
 ├── Google Calendar API
 ├── Database
 ├── GitHub API
 └── Slack API

Every integration is different.

With MCP

MCP provides a common interface:


                ┌── Gmail
                ├── Database
LLM → AI Agent → MCP → GitHub
                ├── Calendar
                └── Slack

The AI doesn't need to understand every API's implementation. It can interact with MCP tools using a standardized protocol.

The 3 important concepts

1. MCP Client

Usually your AI application/agent.


Claude / AI Agent / Your App
        ↓
    MCP Client

2. MCP Server

A program that exposes capabilities to the AI.

For example:


MCP Server
 ├── get_contacts()
 ├── create_contact()
 ├── search_contacts()
 └── delete_contact()

3. Tools / Resources

The MCP server can expose:

  • Tools → things the AI can do
  • Resources → information the AI can read
  • Prompts → reusable prompt templates

Simple example

Suppose you're building your Castanet AI agent.

User says:

"Who should I follow up with today?"

The flow could be:


User
 ↓
LLM
 ↓
AI Agent
 ↓
MCP Client
 ↓
Castanet MCP Server
 ↓
MongoDB
 ↓
Contacts

The MCP server could expose:


get_due_contacts()

The LLM decides:

"I need to call get_due_contacts."

MCP handles the standardized communication between the agent and your server.

MCP vs API

This is an important distinction:

API


Your app → REST API → Server

MCP


LLM/Agent → MCP → Tools/APIs/Database

MCP doesn't replace APIs.

You can actually build an MCP server on top of your existing APIs:


                LLM
                ↓
            AI Agent
                ↓
            MCP Client
                ↓
         Castanet MCP Server
                ↓
         Existing REST API
                ↓
             MongoDB

So if you already know React + Node.js + APIs + MongoDB, MCP is not a completely new backend paradigm. It's primarily a standardized interface for giving AI access to capabilities and context.

MCP + LLM + AI Agent

The easiest mental model is:


LLM = Brain
AI Agent = Brain + decision/action loop
MCP = Standard connector to tools/data
MCP Server = Provides those tools/data

For example:


                  ┌─ Search contacts
                  ├─ Get overdue contacts
LLM → Agent → MCP ├─ Create follow-up
                  ├─ Read analytics
                  └─ Update contact

That's why MCP is particularly useful when you're building AI agents that need to interact with real applications, rather than just generate text.
