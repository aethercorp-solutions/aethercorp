High-Dimensional Space

Think of high-dimensional space as a way of describing something using many numbers at the same time.

Start with normal space

You already know:

  • 1 dimension: a line → x
  • 2 dimensions: a flat map → (x, y)
  • 3 dimensions: physical space → (x, y, z)

For example:


Point A = (2, 5, 3)

That means the point has 3 coordinates.

Now imagine 100 dimensions

A point could be:


A = (
  0.12,
  -0.83,
  0.44,
  0.91,
  0.03,
  ...
  0.71
)

There might be 100, 1,000, or even thousands of numbers.

That's a high-dimensional vector.

The important idea is:

A dimension is simply one independent number used to describe something.

Why does AI use high-dimensional space?

This is where vectors become very useful.

Suppose we want a computer to represent these sentences:

"I love dogs."

"Dogs are my favorite animals."

"The stock market crashed today."

The computer converts each sentence into a vector.

For example, imagine only 5 dimensions:


"I love dogs"
       ↓
[0.82, 0.15, 0.91, 0.04, 0.77]

"Dogs are my favorite animals"
       ↓
[0.79, 0.18, 0.88, 0.06, 0.74]

"The stock market crashed today"
       ↓
[0.12, 0.91, 0.03, 0.82, 0.21]

The first two vectors are similar because their numerical patterns are similar.

The third is very different.

In a real AI system, instead of 5 dimensions, an embedding might have hundreds or thousands of dimensions.

A useful mental picture

Imagine every piece of information is a point in space.

In 2D:


                Dogs
                ●
            ●
         Dogs
               
                           ●
                      Stock market

Related concepts tend to appear near one another.

In a high-dimensional space, you can't physically draw all the dimensions, but mathematically the same concept applies:


                High-dimensional space

                Dog ●
                   ● Puppy
                     ● Cat
                          ● Animal
                                 
                                                             
                                               ● Stock
                                                  ● Finance

The computer doesn't need to "see" this space.

It works with the numbers representing the coordinates.

What does each dimension mean?

This is an important point.

You might think:

"Dimension 1 = dogs, dimension 2 = cats, dimension 3 = money..."

Usually not.

In modern neural-network embeddings, individual dimensions generally don't have such clean human-readable meanings.

Instead, information is distributed across many dimensions.

For example, conceptually:


Dog

Dimension 1:  0.82
Dimension 2: -0.14
Dimension 3:  0.71
Dimension 4:  0.33
Dimension 5: -0.52
...
Dimension 768: 0.19

The combination of all 768 values represents the information.

That's why it's called a representation.

Why so many dimensions?

Because real-world information is complicated.

Consider a person:


Paul

You could potentially represent characteristics such as:


programming
iOS
React
AWS
mobile
AI
cloud
databases
experience
technology
...

But AI doesn't necessarily assign one dimension to each of those concepts.

Instead, thousands of numerical dimensions can collectively encode complex relationships.

So you can think of high-dimensional space as an enormous mathematical coordinate system for representing patterns.

The really powerful part: distance

Once information has been converted into vectors, we can calculate how close or far apart two vectors are.

For example:


Vector A = [0.8, 0.7, 0.9]
Vector B = [0.81, 0.69, 0.88]

Vector C = [0.1, 0.9, 0.2]

A and B are close.

A and C are farther apart.

Therefore:


A ≈ B
A ≠ C

AI systems can use mathematical measures such as cosine similarity to quantify this.

For example:


similarity(A, B) = 0.98
similarity(A, C) = 0.31

So the computer can conclude:

A and B are highly similar.

This is extremely important for RAG

Suppose you have thousands of documents:


Database
│
├── document 1
├── document 2
├── document 3
├── document 4
├── ...
└── document 100,000

You convert their text into vectors:


Document 1 → [0.21, 0.73, ... 768 numbers]
Document 2 → [0.18, 0.70, ... 768 numbers]
Document 3 → [0.92, 0.11, ... 768 numbers]
...

Then the user asks:

"How do I reset my password?"

The question is also converted into a vector:


Question → [0.20, 0.71, ... 768 numbers]

The vector database searches for vectors mathematically close to the question.

It might find:


Question
   │
   ├── 0.97 → "Password reset procedure"
   ├── 0.91 → "Account recovery"
   ├── 0.87 → "Changing your password"
   └── 0.22 → "Database backup procedure"

The closest documents are retrieved.

Then the LLM receives those documents and generates the answer.

The simplest definition

You can remember it this way:

High-dimensional space is a mathematical space where objects are represented using many coordinates (numbers), allowing computers to measure relationships such as similarity, distance, and direction.

And for AI:


Real-world information
        ↓
      Vector
        ↓
High-dimensional space
        ↓
Measure relationships
        ↓
Find similar information
        ↓
AI uses the result

So when people say "embeddings place information in a high-dimensional space," they're essentially saying:

AI converts information into long lists of numbers, and those numbers give each piece of information a position in a huge mathematical space. Similar information tends to have nearby positions.
