# Where Does TensorFlow Help?

Without TensorFlow, you'd have to write code like this:
  1. Predict
  2. Compute error
  3. Compute derivatives (calculus)
  4. Update thousands or millions of weights
  5. Repeat thousands of times


That's incredibly difficult.

TensorFlow automates those steps.

# So What Does `fit()` Actually Do?

When you write:

```python
model.fit(x_train, y_train, epochs=100)

TensorFlow is essentially doing this behind the scenes:


Repeat 100 times:

    Make a prediction

    Measure how wrong it is

    Figure out which weights caused the error

    Adjust those weights a tiny bit

Repeat

After thousands of repetitions, the weights represent patterns found in your data.

The key idea to remember

A neural network doesn't store rules like:

"If house size > 1000 then price = ..."

Instead, it stores millions of carefully adjusted numbers (weights). Those numbers collectively capture patterns in the data. Training is nothing more than repeatedly adjusting those numbers until the predictions become accurate.

Once this idea clicks—that AI learns by changing numbers, not by writing new code—the rest of TensorFlow becomes much easier to understand.

Excellent question. No. The knobs are not algorithms. They are just numbers.

This distinction is one of the biggest "aha!" moments in understanding AI.

Think of it this way

A normal program is made of algorithms.


if temperature > 30:
    turn_on_aircon()
else:
    turn_off_aircon()

You, the programmer, wrote the rule.

A neural network has no such rules.

Instead, it starts with something like this:


Weight 1 = 0.42
Weight 2 = -1.73
Weight 3 = 2.19
Weight 4 = 0.08
...

These are just floating-point numbers.

So where is the algorithm?

The algorithm is TensorFlow's training process, not the weights.

There are two separate things:

1. The learning algorithm (written by TensorFlow)

This algorithm never changes.

It always does something like:


Predict

↓

Calculate error

↓

Calculate gradients

↓

Update weights

↓

Repeat

This is the algorithm.

2. The weights (what the model learns)

These change constantly.


Before

0.52
-1.2
3.8

↓

After training

0.01
5.4
-0.8

TensorFlow changes these numbers millions of times.

An analogy: A Sound Mixing Board

Imagine a music studio.

The recipe "learns" by changing quantities, not by inventing new cooking techniques.

The quantities are like the weights.

Then what is a neuron?

A neuron is just a small mathematical function.

For one input, it roughly does this:


output = input × weight + bias

For example:


Input = 10

Weight = 2

Bias = 3

Output = 10 × 2 + 3 = 23

That's it.

No intelligence.

Just multiplication and addition.

When you connect millions of these tiny calculations together, the network can represent very complex patterns.

Why does this become "intelligent"?

Imagine one neuron can't recognize a cat.

But millions of neurons can work together:


Image

↓

↓

Final neuron:
"If I see eyes + ears + whiskers...
it's probably a cat."

No neuron knows what a cat is.

Each only performs a tiny mathematical operation.

The intelligence emerges from millions of simple operations working together.

The complete picture


                TensorFlow
        (training algorithm)
                    │
                    ▼
        Changes millions of weights
                    │
                    ▼
    Neural network computes outputs
                    │
                    ▼
        Better and better predictions

So:

  • ✅ Algorithm = the procedure that updates the weights (e.g., gradient descent, Adam optimizer).
  • ✅ Weights (knobs) = numbers that are adjusted during learning.
  • ❌ Weights are not pre-programmed algorithms.

A helpful way to think about it is: TensorFlow is like a mechanic with a wrench, and the weights are the bolts on the machine. The mechanic (the learning algorithm) knows how to tighten or loosen bolts, but the bolts themselves are just adjustable values. By adjusting millions of them, the machine (the neural network) gradually performs its task better.
