Supabase

Supabase is an open-source Backend-as-a-Service (BaaS) built on PostgreSQL. It provides the backend infrastructure needed to build web and mobile applications without managing servers yourself.

Its main features include:

  • PostgreSQL Database – A fully managed relational database.
  • Authentication – Email/password, OAuth (Google, GitHub, Apple, etc.), magic links, phone authentication, and more.
  • Real-time – Listen for database changes instantly using WebSockets.
  • Storage – Store and serve images, videos, documents, and other files.
  • Edge Functions – Run serverless functions close to users using Deno.
  • Row Level Security (RLS) – PostgreSQL-based security rules to control data access.
  • Auto-generated APIs – Every table automatically gets REST and GraphQL APIs.

Example

Creating a Supabase client in JavaScript:


import { createClient } from '@supabase/supabase-js'

const supabase = createClient(
  'https://your-project.supabase.co',
  'your-anon-key'
)

Fetching data:


const { data, error } = await supabase
  .from('users')
  .select('*')

When to use Supabase

Supabase is a good choice if you need:

  • User authentication
  • A PostgreSQL database
  • File storage
  • Real-time updates
  • Serverless backend functionality
  • Fast MVP or startup development
