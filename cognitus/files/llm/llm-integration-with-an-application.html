LLM Integration with an Application

LLM (Large Language Model) integration means connecting an application to an AI model such as Claude, GPT, or Gemini so your software can understand natural language, analyze data, generate responses, summarize documents, and automate tasks.

As a full-stack developer using Node.js, React, and mobile technologies, you can integrate an LLM into web applications, backend services, and iOS or React Native apps.

1. How LLM integration works 


1. Frontend application

React, React Native, Flutter, or SwiftUI

User enters a question or submits a document.
            

2. Backend API

Node.js + Express or AWS Lambda

Authenticates the user, validates input, and prepares the prompt.
            

3. LLM provider

OpenAI, Anthropic Claude, or Google Gemini

Processes the prompt and returns an AI-generated response.
            

4. Application logic and data

MongoDB, PostgreSQL, internal APIs, or vector databases

Optionally retrieves relevant data, validates results, and executes authorized actions.
            

5. Response to the user

The frontend displays the generated answer or completed task.

The important point is that the LLM is one component of the application. Your backend still controls authentication, business rules, database access, and security.

2. Example: Integrating Claude with Node.js

Suppose you are building a contact management application and want users to ask AI to summarize contact notes.

Step 1: Install the SDK


npm install express @anthropic-ai/sdk dotenv

Create a .env file:


ANTHROPIC_API_KEY=your_api_key_here

Keep the API key on the server. Never expose it in React, React Native, Flutter, or iOS client code.

Step 2: Create the backend endpoint


import express from "express";
import Anthropic from "@anthropic-ai/sdk";
import "dotenv/config";

const app = express();
app.use(express.json());

const anthropic = new Anthropic({
  apiKey: process.env.ANTHROPIC_API_KEY
});

app.post("/api/summarize", async (req, res) => {
  try {
    const { notes } = req.body;

    if (typeof notes !== "string" || !notes.trim()) {
      return res.status(400).json({
        error: "Notes are required"
      });
    }

    const response = await anthropic.messages.create({
      model: "claude-sonnet-4-5",
      max_tokens: 300,
      messages: [
        {
          role: "user",
          content: `Summarize these contact notes in three concise bullet points: ${notes}`
        }
      ]
    });

    const summary = response.content
      .filter(block => block.type === "text")
      .map(block => block.text)
      .join("\n");

    res.json({ summary });
  } catch (error) {
    console.error("LLM request failed", error);

    res.status(500).json({
      error: "Unable to generate summary"
    });
  }
});

app.listen(3000, () => {
  console.log("Server running on port 3000");
});

This model identifier is an example; confirm that it is available for your Anthropic account before deploying.

Step 3: Call the API from React


async function summarizeContact(notes) {
    const response = await fetch("/api/summarize", {
        method: "POST",
        headers: {
        "Content-Type": "application/json"
        },
        body: JSON.stringify({ notes })
    });
    
    if (!response.ok) {
        throw new Error("Failed to summarize contact");
    }
    
    const result = await response.json();
    
    return result.summary;
}

When the user clicks Summarize, your frontend calls the Node.js endpoint. The backend sends the notes to Claude and returns the generated summary.
