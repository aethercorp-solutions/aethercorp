Promise in TypeScript

A Promise in TypeScript (and JavaScript) is an object that represents a value you don't have yet, but will get in the future.

Think of ordering food at a restaurant.

  • You order food → You get a receipt (the Promise).
  • The kitchen prepares the food.
  • Later, one of two things happens:
    • ✅ Your food is ready (resolved).
    • ❌ The restaurant says they ran out of ingredients (rejected).

The receipt is not the food—it just promises you'll eventually get an answer.

Without a Promise

Imagine a function that returns immediately.


function getName() {
    return "Paul";
}

const name = getName();
console.log(name);

Output:


Paul

The value is available immediately.

With a Promise

Sometimes getting data takes time.

For example:

  • Downloading from an API
  • Reading a file
  • Accessing a database

function getName(): Promise<string> {
    return Promise.resolve("Paul");
}

Notice:


Promise<string>

means:

"I don't have a string yet, but I promise I'll give you one later."

Visual Timeline

      ▼

Using .then()


function getName(): Promise<string> {
    return Promise.resolve("Paul");
}

getName().then((name) => {
    console.log(name);
});

Output


Paul

The .then() runs after the Promise finishes.

Using async/await (much easier)

Instead of .then(), we usually write:


async function main() {
    const name = await getName();
    console.log(name);
}

main();

await means:

"Pause here until the Promise finishes."

Example with an API


async function fetchUser(): Promise<string> {
    return "Paul";
}

async function main() {
    const user = await fetchUser();
    console.log(user);
}

main();

Flow:


fetchUser()
      │
      ▼
Promise<string>
      │
await
      │
      ▼
"Paul"

Promise can succeed or fail

Success


Promise.resolve("Success")

Failure


Promise.reject("Something went wrong")

Example:


async function login(): Promise<string> {
    throw new Error("Wrong password");
}

Handle it:


async function main() {
    try {
        const result = await login();
        console.log(result);
    } catch (error) {
        console.log("Login failed");
    }
}
    
main();

Why APIs return Promises

Suppose you request data from a server.


Your App  ------------> Server
              waiting...
Your App <------------ Data

The server might take:

  • 100 ms
  • 2 seconds
  • 10 seconds

Your program can't freeze while waiting, so it gets a Promise immediately and continues doing other work. When the server responds, the Promise is fulfilled.

Breaking down this code


async function fetchUser(): Promise<string> {
    return "Paul";
}

Step 1


async function fetchUser()

async tells TypeScript:

"This function always returns a Promise."

Even if you return a plain string, TypeScript wraps it automatically.

So this:


async function fetchUser() {
    return "Paul";
}

is equivalent to:


function fetchUser() {
    return Promise.resolve("Paul");
}

Step 2


: Promise<string>

means:

"The Promise will eventually contain a string."

Not immediately:


Now:
Promise

Later:
"Paul"

Another example


async function getAge(): Promise<number> {
    return 25;
}

This is equivalent to:


function getAge() {
    return Promise.resolve(25);
}

Promise types


Promise<string>      // later returns a string

Promise<number>      // later returns a number

Promise<boolean>     // later returns true/false

Promise<User>        // later returns a User object

Promise<User[]>      // later returns an array of users

Real-world analogy

Imagine ordering a package online.


Today
│
├── You place the order.
│
├── The store gives you an order receipt.
│      ↑
│   This is the Promise.
│
└── Wait...

Later:


Tomorrow
│
├── Delivery arrives ✅
│
└── OR

Package is canceled ❌

The receipt isn't the package—it represents the promise that you'll eventually receive either the package (success) or a cancellation (failure).

Summary

  • A Promise represents a value that will be available later.
  • Promise<T> means "I'll eventually return a value of type T."
  • async functions always return a Promise.
  • await waits for the Promise to finish and gives you its resolved value.
  • Promises are commonly used for operations that take time, such as API requests, database queries, and file operations.
