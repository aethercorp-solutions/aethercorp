Advanced TypeScript Features

Advanced TypeScript features help you write safer, smarter, and more reusable code. Here's a simple explanation of the most useful ones.

1. Generics

Create code that works with any type.

Without generics:


function getFirst(arr: string[]): string {
    return arr[0];
}

With generics:


function getFirst(arr: T[]): T {
    return arr[0];
}

getFirst([1, 2, 3]);       // number
getFirst(["a", "b"]);      // string

Think of it as:

"I don't care what type it is. Just keep it consistent."

2. keyof

Get all property names of an object.


interface User {
    name: string;
    age: number;
}

type Keys = keyof User;

Keys becomes:


"name" | "age"

Useful for preventing invalid property names.


function getValue<T, K extends keyof T>(obj: T, key: K) {
    return obj[key];
}

getValue(user, "name"); // ✅
getValue(user, "email"); // ❌ Error

3. extends

Limit what types are allowed.


function printLength<T extends { length: number }>(item: T) {
    console.log(item.length);
}

Works:


printLength("Hello");
printLength([1, 2, 3]);

Doesn't work:


printLength(100);

because numbers don't have length.

4. Union Types

One variable can have multiple possible types.


let id: string | number;

id = 1;
id = "ABC";

Like saying:

"This can be either a string or a number."

5. Intersection Types

Combine multiple types together.


type Person = {
    name: string;
};

type Employee = {
    salary: number;
};

type Staff = Person & Employee;

Now:


const user: Staff = {
    name: "John",
    salary: 50000
};

Think:

Merge two objects into one.

6. Utility Types

Partial

Makes every property optional.


interface User {
    name: string;
    age: number;
}
    
type UpdateUser = Partial<User>;

Now:


{
    name: "Paul"
}

is valid.

Pick

Choose only certain properties.


type BasicUser = Pick<User, "name">

Result:


{
    name: string;
}

Omit

Remove properties.


type UserWithoutAge = Omit<User, "age">;

Result:


{
    name: string;
}

Readonly

Prevent changes.


const user: Readonly<User> = {
    name: "Paul",
    age: 25
};

user.age = 30; // Error

7. Mapped Types

Transform every property in an object.


type Optional<T> = {
    [K in keyof T]?: T[K];
};

Instead of writing optional versions manually.

8. Conditional Types

If-else for types.


type IsString<T⥸ =
    T extends string ? true : false;

Examples:


IsString<string> // true
    IsString<number> // false

9. infer

Automatically extract a type.


type Return<T> =
    T extends (...args: any[]) => infer R
        ? R
        : never;

Example:


function add() {
    return 10;
}

type Result = Return<typeof add>;

Result becomes:


number

10. Type Guards

Help TypeScript know the type during runtime.


function print(id: string | number) {
    if (typeof id === "string") {
        console.log(id.toUpperCase());
    } else {
        console.log(id.toFixed(2));
    }
}

TypeScript understands which methods are safe in each branch.

11. Discriminated Unions

Useful when objects have different shapes.


type Circle = {
    kind: "circle";
    radius: number;
};

type Square = {
    kind: "square";
    size: number;
};

type Shape = Circle | Square;

function area(shape: Shape) {
    if (shape.kind === "circle") {
        return Math.PI * shape.radius ** 2;
    }

    return shape.size * shape.size;
}

12. Async Type (Awaited)

Extract the resolved value of a Promise.


type Result = Awaited<Promise<string>>;

Result:


string

Real-world example (React API)


interface User {
    id: number;
    name: string;
}

async function getUser(): Promise<User> {
    const res = await fetch("/api/user");
    return res.json();
}

type UserData = Awaited<ReturnType<typeof getUser>>;

UserData automatically becomes:


User

No need to write it twice.

Quick summary

Feature Simple meaning
Generics Reuse code for any type
keyof Get object property names
extends Restrict allowed types
Union (|) One of several types
Intersection (&) Combine multiple types
Partial Make all properties optional
Pick Select specific properties
Omit Remove specific properties
Readonly Prevent modifications
Mapped Types Transform every property in a type
Conditional Types If-else logic for types
infer Automatically extract a type
Type Guards Narrow types safely at runtime
Discriminated Unions Safely handle different object shapes
Awaited Get the value inside a Promise

Once you're comfortable with interfaces, classes, and basic types, these advanced features make TypeScript especially powerful by catching more errors at compile time while reducing repetitive code.
