express.Router() as a mini Express application

Think of express.Router() as a mini Express application that lets you organize related routes into separate files.

Without Router, all routes go into one file:


const express = require('express');
const app = express();

app.get('/users', (req, res) => {
    res.send('Get users');
});

app.post('/users', (req, res) => {
    res.send('Create user');
});

app.get('/products', (req, res) => {
    res.send('Get products');
});

app.listen(3000);

As your application grows, this file becomes huge.

Using express.Router()

Create a separate file for user routes.

routes/users.js


const express = require('express');
const router = express.Router();

router.get('/', (req, res) => {
    res.send('Get users');
});

router.post('/', (req, res) => {
    res.send('Create user');
});

module.exports = router;

app.js


const express = require('express');
const app = express();

const userRoutes = require('./routes/users');

app.use('/users', userRoutes);

app.listen(3000);

Now:


GET  /users
POST /users

work automatically.

What happens internally?

When Express sees:


app.use('/users', userRoutes);

it means:

"For any URL starting with /users, pass the request to this router."

Inside the router:


router.get('/', ...)

actually becomes:


/users + /
= /users

and


router.get('/profile', ...)

becomes:


/users/profile

Visual Flow


Browser
   |
GET /users/profile
   |
Express App
   |
app.use('/users', userRoutes)
   |
Users Router
   |
router.get('/profile')
   |
Response

Multiple Routers

routes/users.js


const router = express.Router();

router.get('/', (req, res) => {
    res.send('Users');
});

module.exports = router;

routes/products.js


const router = express.Router();

router.get('/', (req, res) => {
    res.send('Products');
});

module.exports = router;

app.js


app.use('/users', require('./routes/users'));
app.use('/products', require('./routes/products'));

Requests:


GET /users      -> Users Router
GET /products   -> Products Router

Router Middleware

A router can have middleware that only applies to that router.


const router = express.Router();

router.use((req, res, next) => {
    console.log('Users router middleware');
    next();
});

router.get('/', (req, res) => {
    res.send('Users');
});

Request:


GET /users

Output:


Users router middleware

Real Backend Structure


project/
│
├── app.js
│
├── routes/
│   ├── auth.js
│   ├── users.js
│   └── products.js
│
├── controllers/
│   ├── authController.js
│   ├── userController.js
│   └── productController.js
│
└── middleware/
    └── auth.js

routes/users.js


const express = require('express');
const router = express.Router();
const userController = require('../controllers/userController');

router.get('/', userController.getUsers);
router.get('/:id', userController.getUser);
router.post('/', userController.createUser);

module.exports = router;

app.js


app.use('/api/users', require('./routes/users'));

Routes become:


GET  /api/users
GET  /api/users/123
POST /api/users

Simple mental model


Express App
   |
   +-- /users ----> Users Router
   |
   +-- /products -> Products Router
   |
   +-- /auth -----> Auth Router

express.Router() is simply a way to group related routes and middleware together, making large Node.js/Express applications easier to maintain.
