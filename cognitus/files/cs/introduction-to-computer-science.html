Introduction to Computer Science

If you're looking for an introduction to computer science (rather than machine learning), these are among the best beginner-friendly books:

1. Code: The Hidden Language of Computer Hardware and Software — Charles Petzold ⭐ Best absolute beginner

Level: No programming experience

This book explains:

  • How computers represent numbers
  • Binary and logic gates
  • CPUs and memory
  • How software runs on hardware

It's one of the best books for understanding what a computer actually is.

2. Computer Science: An Interdisciplinary Approach

Level: Beginner

Covers:

  • Programming
  • Algorithms
  • Data structures
  • Graphics
  • Scientific computing

It teaches computer science from first principles using practical examples.

3. How Computers Really Work

Level: Beginner

A visual, approachable introduction to:

  • CPUs
  • Memory
  • Operating systems
  • Networking
  • Programming

Ideal if you like diagrams and intuitive explanations.

4. Grokking Algorithms

Level: Beginner

A highly visual introduction to:

  • Searching
  • Sorting
  • Recursion
  • Graphs
  • Dynamic programming

Excellent if you're learning to program.

5. Computer Systems: A Programmer's Perspective

Level: Intermediate

Teaches:

  • Machine code
  • Memory hierarchy
  • Processes
  • Virtual memory
  • Linking
  • Performance

This is a standard university textbook and a great next step after the basics.

6. Structure and Interpretation of Computer Programs (SICP)

Level: Intermediate to Advanced

A classic that develops deep understanding of:

  • Programming languages
  • Abstraction
  • Functional programming
  • Interpreters
  • Compilers

It's intellectually demanding but highly rewarding.

If you're interested in AI or machine learning

Start with these after learning basic programming:

  • Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow — practical machine learning with Python.
  • Artificial Intelligence: A Modern Approach — the standard university AI textbook.
  • Deep Learning — comprehensive deep learning reference.

Recommended learning path

  1. Code → Understand how computers work.
  2. Grokking Algorithms → Learn problem-solving and algorithms.
  3. Computer Science: An Interdisciplinary Approach → Build a broad CS foundation.
  4. Computer Systems: A Programmer's Perspective → Learn how software interacts with hardware.
  5. SICP → Develop a deeper understanding of programming concepts.
  6. Move into AI, machine learning, operating systems, compilers, or other advanced topics based on your interests.

Since you're already an experienced software developer, you'll likely progress quickly through the first few books and may find Computer Systems: A Programmer's Perspective and SICP especially valuable for strengthening your theoretical foundation.
