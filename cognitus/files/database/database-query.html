SQL queries vs Mongodb queries

Think of it like this: SQL queries are like filling out a strict form, while MongoDB queries are like searching through flexible notes or JSON documents.

🧾 SQL (Structured Query Language)

Used in traditional relational databases like MySQL, PostgreSQL, etc.

How it works:

  • Data is stored in tables (like Excel sheets)
  • Every row has fixed columns
  • You must follow a strict structure

Example:


SELECT name, age
FROM users
WHERE age > 18;

Key idea:

You are telling the database:

“Go to this table, pick these columns, and filter rows like this.”

🍃 MongoDB Query

Used in MongoDB

How it works:

  • Data is stored as documents (JSON-like objects)
  • Each record can have different fields
  • More flexible structure

Example:


db.users.find({
    age: { $gt: 18 }
    }, {
    name: 1,
    age: 1
});

Key idea:

You are telling the database:

“Find documents that match this pattern.”

⚖️ Simple Difference

Feature SQL MongoDB
Data format Tables (rows & columns) JSON-like documents
Structure Fixed Flexible
