HTTP request header

An HTTP request header is extra information that your app sends to a server along with a request. It tells the server who is making the request, what kind of data is being sent, how to respond, and other details.

Think of it like sending a package:

  • URL = the destination address
  • Body = what's inside the package
  • Headers = the label on the package (who sent it, what's inside, special instructions)

Example HTTP Request


POST /api/login HTTP/1.1
Host: api.example.com
Content-Type: application/json
Authorization: Bearer eyJhbGciOi...
User-Agent: MyApp/1.0

{
  "email": "user@example.com",
  "password": "password123"
}

Common Request Headers

Header Purpose
Host Which server to send the request to.
Content-Type The format of the data being sent (e.g. application/json).
Authorization Sends authentication information such as a JWT or OAuth token.
User-Agent Identifies the app, browser, or device making the request.
Accept Specifies the response formats the client can accept.
Accept-Language Preferred language for the response.

JavaScript Example


fetch("https://api.example.com/profile", {
    method: "GET",
    headers: {
        Authorization: "Bearer YOUR_TOKEN",
        Accept: "application/json",
        "User-Agent": "MyApp/1.0"
    }
});

Express/Node.js Example

On the server, you can read headers like this:


app.get("/profile", (req, res) => {
    console.log(req.headers);
    
    console.log(req.headers.authorization);
    console.log(req.headers["user-agent"]);
    console.log(req.headers["content-type"]);
    
    res.send("OK");
});

Example of req.headers


{
    host: "api.example.com",
    authorization: "Bearer eyJhbGc...",
    "content-type": "application/json",
    "user-agent": "Castanet/5 CFNetwork/3826.600.41.2.1 Darwin/24.6.0",
    accept: "application/json"
}

Why are headers important?

Headers are commonly used for:

  • 🔐 Authentication (Authorization)
  • 📦 Describing the data format (Content-Type)
  • 📱 Identifying the client (User-Agent)
  • 🌍 Language preferences (Accept-Language)
  • 📄 Telling the server what response format is expected (Accept)

In short, the request body contains the main data you want to send, while the request headers provide instructions and metadata about that request.
