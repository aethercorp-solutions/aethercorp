struct

In Swift, a struct (structure) is a custom data type that groups related data and functions into one reusable unit. You use it to represent things such as inventory items, users, contacts, API responses, or products in an iOS application.

Think of a struct as a blueprint for creating objects that hold data.

1. Basic Swift struct 


struct InventoryItem {
    let id: Int
    var name: String
    var quantity: Int
}

Here is what each part means:

  • struct InventoryItem — defines a new data type.
  • let id: Int — a constant ID that cannot be changed.
  • var name: String — a name that can be changed.
  • var quantity: Int — a quantity that can be changed.

2. Create and use a struct


struct InventoryItem {
    let id: Int
    var name: String
    var quantity: Int
}

// Create an instance
var item = InventoryItem(
    id: 101,
    name: "iPhone",
    quantity: 10
)

// Read the properties
print(item.name)      // iPhone
print(item.quantity)  // 10

// Update a property
item.quantity = 15

print(item.quantity)  // 15

3. Struct can contain functions

A struct can contain both data (properties) and behavior (methods).


struct InventoryItem {
    var name: String
    var quantity: Int

    func displayInfo() -> String {
        return "\(name): \(quantity) units"
    }

    mutating func addStock(_ amount: Int) {
        quantity += amount
    }
}

var item = InventoryItem(
    name: "MacBook",
    quantity: 5
)

print(item.displayInfo())
// MacBook: 5 units

item.addStock(10)

print(item.quantity)
// 15

Notice mutating in addStock().

In a struct, a method needs the mutating keyword when it modifies the struct's own stored properties.

4. What is the difference between struct and class?

This is one of the most important concepts in modern Swift.

Feature struct class
Type Value type Reference type
Inheritance No class inheritance Supports inheritance
Copy behavior Copies the value Shares a reference to the same instance
Mutating properties Often requires a var instance Can modify properties through a let reference when permitted
Common uses Models, API data, SwiftUI views Shared objects, services, UIKit controllers

The key difference: value vs. reference

Struct example:


struct User {
    var name: String
}

var user1 = User(name: "Paul")
var user2 = user1

user2.name = "John"

print(user1.name) // Paul
print(user2.name) // John

user2 receives its own value. Changing it does not change user1.

Class example:


class User {
    var name: String

    init(name: String) {
        self.name = name
    }
}

let user1 = User(name: "Paul")
let user2 = user1

user2.name = "John"

print(user1.name) // John

Both variables refer to the same class instance, so the change is visible through both references.

5. Why structs are important in modern iOS development

In a well-organized Swift application, structs are commonly used to separate your data from your business logic and user interface.

For example, an inventory app might use this structure:


Model — InventoryItem.swift
Defines inventory data: ID, name, quantity, barcode.

Service — InventoryService.swift
Fetches inventory from an API and decodes JSON.

ViewModel — InventoryViewModel.swift
Manages application state and coordinates data operations.

View — SwiftUI or UIKit
Displays inventory and handles user interaction.

For example, a struct can represent JSON received from your backend:


struct InventoryItem: Codable, Identifiable {
    let id: Int
    var name: String
    var quantity: Int
}
  • Codable allows Swift to encode and decode the model to and from formats such as JSON.
  • Identifiable gives each item a stable identity for lists and other UI features.
  • The struct defines the data; it does not need to handle networking or screen rendering itself.
