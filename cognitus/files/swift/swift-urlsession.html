URLSession

URLSession is Swift/iOS's built-in way to communicate with a server over the internet.

Think of it like this:


Your iOS App
    ↓
URLSession
    ↓
Internet
    ↓
API Server
    ↓
Database

Simple example

Suppose your API is:


GET https://api.example.com/users

Swift:


import Foundation

let url = URL(string: "https://api.example.com/users")!

let task = URLSession.shared.dataTask(with: url) { data, response, error in

    if let error = error {
        print("Error:", error)
        return
    }

    guard let data = data else {
        return
    }

    print(String(data: data, encoding: .utf8) ?? "")
}

task.resume()

What is happening?

1. Create the URL


let url = URL(string: "https://api.example.com/users")!

You're telling the app where the API is.

2. Create a request


URLSession.shared.dataTask(with: url)

URLSession creates a network request.

3. Wait for the server


{ data, response, error in

The closure runs when the request finishes.

You get:

  • data → response body
  • response → HTTP information/status code
  • error → networking error

4. Start the request


task.resume()

This is important. Without resume(), the request doesn't actually start.

POST request

For example, logging in:


var request = URLRequest(
    url: URL(string: "https://api.example.com/login")!
)

request.httpMethod = "POST"
request.setValue("application/json", forHTTPHeaderField: "Content-Type")

request.httpBody = try? JSONEncoder().encode([
    "email": "test@example.com",
    "password": "123456"
])

let task = URLSession.shared.dataTask(with: request) { data, response, error in
    // Handle response
}

task.resume()

The important difference is that URLRequest lets you configure:


HTTP method
Headers
Body
URL

Modern Swift

Today, you will often see async/await instead of completion handlers:


let url = URL(string: "https://api.example.com/users")!

let (data, response) = try await URLSession.shared.data(from: url)

let users = try JSONDecoder().decode([User].self, from: data)

This is much easier to read:


URLSession
   ↓
send request
   ↓
await response
   ↓
decode JSON
   ↓
User objects
