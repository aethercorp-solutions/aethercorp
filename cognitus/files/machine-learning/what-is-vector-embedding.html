What is a Vector Embedding?

Imagine you have words, sentences, images, or documents.

Simple Explanation

Imagine you have words, sentences, images, or documents.

A computer cannot directly understand meaning, so an AI model converts them into a list of numbers called a vector embedding.

Example:


"dog"  → [0.23, -0.81, 0.45, 0.92, ...]
"puppy"→ [0.25, -0.79, 0.47, 0.89, ...]
"car"  → [-0.65, 0.12, -0.34, 0.08, ...]

Because "dog" and "puppy" have similar meanings, their vectors are close together.

Think of embeddings as:

A GPS coordinate for meaning.

Just as places have latitude and longitude, words and documents have embedding coordinates.

Why Use Vector Embeddings?

Traditional search:


Query: "How to build a banking app"

Matches:
✓ "How to build a banking app"
✗ "Creating a fintech application"

Vector search:


Query: "How to build a banking app"

Matches:
✓ "Creating a fintech application"
✓ "Developing a digital wallet"
✓ "Building payment systems"

Because it understands meaning, not just keywords.

Basic Algorithm

Step 1: Convert Text to Embeddings


const embedding = embeddingModel.embed(
  "How to build a banking app"
);

Result:


[0.34, -0.52, 0.91, ...]

Step 2: Store in Vector Database

Example document:


{
    "text": "Building a fintech application",
    "embedding": [0.33, -0.50, 0.89]
}

Stored in:

  • MongoDB
  • Pinecone
  • Weaviate
  • Milvus

Step 3: Create Query Embedding

User asks:


"How do I create a digital wallet?"

Convert to vector:


[0.35, -0.49, 0.88]

Step 4: Calculate Similarity

Most common algorithm:

Cosine Similarity

Measures angle between vectors.


1.0  = identical
0.8+ = very similar
0.5  = somewhat related
0.0  = unrelated

Earlier you asked about cosine.

Here cosine similarity answers:

"How similar are the meanings of two vectors?"

not their actual distance.

Using MongoDB Vector Search

Since you work with Node.js and MongoDB, a typical flow is:


PDFs/Documents
        ↓
Create Embeddings
        ↓
Store in MongoDB
        ↓
MongoDB Atlas Vector Search
        ↓
Return Top Matching Documents
        ↓
Send Context to LLM
        ↓
Generate Answer

Document example:


{
    "_id": 1,
    "content": "TryCastanet payment processing",
    "embedding": [0.12, 0.45, -0.33, ...]
}

Query:


db.collection.aggregate([
  {
    $vectorSearch: {
      index: "vector_index",
      path: "embedding",
      queryVector: embedding,
      numCandidates: 100,
      limit: 5
    }
  }
]);
