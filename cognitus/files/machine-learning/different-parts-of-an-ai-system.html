Different parts of an AI system

These three terms are related but describe different parts of an AI system.

Think of them like a person using a library.

  • LLM = the person's brain
  • RAG = the library they can look up information in
  • Agent = the person who can decide what tasks to do and use tools

Here's how they differ:

Feature LLM RAG Agent
Main purpose Generate text Retrieve information before generating Perform tasks and make decisions
Has memory? Only what was trained and current context Yes, by searching external documents Can use memory plus tools
Uses external data? No Yes Yes
Can call APIs? No (by itself) Usually no Yes
Can make plans? Very limited No Yes
Can use tools? No No Yes

1. LLM (Large Language Model)

An LLM is just the AI model.

Examples:

  • GPT
  • Llama
  • Gemini
  • Claude

It has learned patterns from huge amounts of text during training.

Example:

You ask:

"What is React?"

LLM answers from what it already learned.


Question
      ↓
+-------------+
|     LLM     |
+-------------+
      ↓
Answer

The LLM cannot automatically search your company's documents or call an API on its own.

2. RAG (Retrieval-Augmented Generation)

RAG gives the LLM access to external knowledge.

Instead of relying only on training data:


Question
      ↓
Search documents
      ↓
Relevant documents
      ↓
LLM
      ↓
Answer

Example:

Imagine your company has:


Employee Handbook.pdf
Vacation Policy.docx
Salary Guide.pdf

You ask:

"How many vacation days do employees receive?"

The system:

  1. Searches the documents.
  2. Finds the vacation policy.
  3. Sends the relevant text to the LLM.
  4. The LLM answers using that information.

Without RAG:


LLM
↓

"I don't know your company's vacation policy."

With RAG:


Search handbook
↓

Vacation policy found
↓

LLM answers correctly.

RAG does not decide what to do next. It simply retrieves relevant information.

3. Agent

An agent is much more capable.

Instead of only answering questions, it can:

  • Plan
  • Reason
  • Use tools
  • Call APIs
  • Search the web
  • Execute code
  • Repeat steps until the task is complete

Example:

You ask:

"Book my meeting for Friday."

The agent might:


Understand request
      ↓
Check calendar
      ↓
Find available time
      ↓
Create calendar event
      ↓
Send invitations
      ↓
Confirm success

This involves multiple decisions and actions, not just text generation.

How they work together

Modern AI applications often combine all three.


              User
                │
                ▼
           AI Agent
         ┌──────┴──────┐
         │             │
         ▼             ▼
       Search       Call APIs
       (RAG)         (Tools)
         │             │
         └──────┬──────┘
                ▼
               LLM
                │
                ▼
            Final Answer

For example, if you ask:

"Summarize yesterday's sales and email the report to my manager."

The system might:

  1. Agent decides the steps.
  2. RAG retrieves yesterday's sales data or reports.
  3. LLM writes a clear summary.
  4. Agent sends the email using your email service.

In AI development

  • Use an LLM when you need text generation, coding assistance, translation, or brainstorming.
  • Add RAG when the AI needs to answer questions using your own documents, databases, or knowledge base.
  • Use an Agent when the AI needs to perform multi-step tasks, make decisions, interact with software, or orchestrate tools.

In practice, many production AI systems are LLM + RAG + Agent: the LLM provides reasoning and language, RAG supplies up-to-date or private knowledge, and the agent coordinates the work and interacts with external systems.
