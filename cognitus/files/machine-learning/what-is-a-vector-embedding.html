What is a Vector Embedding?

Vector embeddings are the foundation of modern AI search, recommendation systems, semantic search, and Retrieval-Augmented Generation (RAG).

What is a Vector Embedding?

A vector embedding is simply a list of numbers that represents the meaning of something.

Example:

Text:

"I love dogs"

Embedding:


[0.21, -0.44, 0.82, 0.15, ...]

Modern AI models produce vectors with hundreds or thousands of dimensions.

For example:

  • OpenAI embeddings: 1536+ numbers
  • Some models: 768 numbers
  • Others: 3072+ numbers

Each number alone means nothing.

The pattern of all numbers together represents meaning.

Dog appears near:
- pet

Eventually it learns relationships.

Then it converts words into vectors.

Example (simplified):


Dog   = [0.8, 0.9, 0.2]
Puppy = [0.7, 0.8, 0.3]
Cat   = [0.75, 0.85, 0.1]
Car   = [0.1, 0.2, 0.9]

Notice:


Dog
Puppy
Cat

are close together.


Car

is far away.

4. Sentence Embeddings

AI doesn't only embed words.

It embeds entire sentences.

Example:


I want a dog

might become:


[0.22, 0.77, -0.11, ...]

And:


I would like a puppy

might become:

Different words.

Same meaning.

Very close vectors.

5. How Semantic Search Works

Traditional search:


Search: dog

Looks for exact keyword:


dog

If document says:


puppy

it might miss it.

Vector Search:

Convert query into embedding:


dog

↓


[0.8, 0.9, 0.2]

Database already stores embeddings.


Document A: puppy
[0.7,0.8,0.3]

Document B: car
[0.1,0.2,0.9]

AI calculates similarity.

Result:


dog ↔ puppy
= very similar

dog ↔ car
= not similar

Therefore:

puppy

is returned even without the word "dog".

6. How Similarity is Calculated

Most systems use:

Cosine Similarity

It measures the angle between vectors.


Same direction
= similarity near 1.0

Different direction
= similarity near 0

Opposite direction
= similarity near -1

Formula:


similarity =
(A · B) / (|A| × |B|)

Think:


Same meaning
→ small angle

Different meaning
→ large angle

7. How AI Search Works

Suppose you have documents:


1. Dogs are loyal pets
2. Cats like climbing
3. Electric cars use batteries

Store embeddings:


Doc1 → Vector
Doc2 → Vector
Doc3 → Vector

User searches:

Which animal is man's best friend?

AI creates query embedding.

Then compares against all document vectors.

Result:


Doc1

because its vector is closest.

Even though:

man's best friend

never appears in the document.

8. How ChatGPT RAG Uses Embeddings

Suppose your company has:


10,000 PDFs

Steps:

Step 1

Split documents into chunks.


Chunk 1
Chunk 2
Chunk 3

Step 2

Create embeddings.

Chunk → Vector

Step 3

Store in vector database.

Examples:

  • Pinecone
  • Weaviate
  • Qdrant
  • Milvus

Step 4

User asks:


What is our refund policy?

Step 5

Question becomes embedding.

Step 6

Nearest chunks found.

Step 7

Relevant chunks sent to LLM.

Step 8

LLM generates answer.

This is Retrieval-Augmented Generation (RAG).

9. Why Dimensions Can Be 1536+

A single dimension might capture tiny patterns such as:


Animalness
Vehicle-ness
Technology
Emotion
Food
Location
Action

But modern models don't manually define dimensions.

They learn them automatically.

Example:


[0.41,
-0.82,
0.12,
...
1536 values]

The entire vector collectively encodes meaning.
