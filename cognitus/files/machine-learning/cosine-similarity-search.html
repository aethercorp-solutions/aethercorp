Cosine Similarity Search

Cosine Similarity Search is a way to find items that are most similar in meaning by comparing their vector embeddings.

Simple Analogy

Imagine each document, sentence, or image is converted into a list of numbers (a vector embedding).

Example:

  • "I love dogs" → [0.8, 0.2, 0.5]
  • "Dogs are amazing pets" → [0.7, 0.3, 0.4]
  • "I like pizza" → [0.1, 0.9, 0.2]

Even though the words are different, the first two vectors point in a similar direction because they have similar meanings.

What Cosine Similarity Measures

Instead of comparing the size of vectors, it compares their direction.

Think of vectors as arrows:


Similar Meaning
      ↗
     ↗
    ↗

Different Meaning
      ↗
      →

The smaller the angle between the arrows, the more similar they are.

Formula

Cosine similarity is:


                Cosine Similarity = (A * B) / |A||B|

Result:

  • 1 = exactly the same direction (very similar)
  • 0 = unrelated
  • -1 = opposite meaning (rare in embeddings)

How Search Works

Suppose your database contains:

Text Embedding
"How to train a dog" Vector A
"Dog obedience tips" Vector B
"Best pizza recipes" Vector C

User searches:

"Teach my puppy commands"

Steps:

  1. Convert query into an embedding vector.
  2. Compare it against all stored vectors using cosine similarity.
  3. Sort by highest score.
  4. Return the closest matches.

Result:


"Dog obedience tips"      0.95
"How to train a dog"      0.92
"Best pizza recipes"      0.10

Why LLM Applications Use It

When building AI apps:

  1. Store document embeddings in a vector database or MongoDB.
  2. User asks a question.
  3. Convert question into an embedding.
  4. Use cosine similarity search to find relevant documents.
  5. Send those documents to the LLM.

This is the basis of RAG (Retrieval-Augmented Generation).

MongoDB Example

MongoDB Atlas supports vector search.


const results = await collection.aggregate([
  {
    $vectorSearch: {
      index: "vector_index",
      path: "embedding",
      queryVector: queryEmbedding,
      numCandidates: 100,
      limit: 5
    }
  }
]);

Internally, MongoDB finds vectors with the highest cosine similarity (or another distance metric).

One-Sentence Summary

Cosine Similarity Search finds the vectors whose directions are closest to a query vector, allowing AI systems to retrieve content with similar meaning rather than just matching keywords.
