Express.js Route

Express.js is a minimal and flexible web application framework for Node.js. It helps developers build:

Official site: Express.js

  • Web servers
  • REST APIs
  • Backend applications
  • Full-stack web apps
  • Real-time services
It simplifies handling:
  • HTTP requests/responses
  • Routing
  • Middleware
  • APIs
  • Static files
  • Authentication
  • Error handling

Why Express.js Exists

Using raw Node.js HTTP modules is verbose.

Example without Express:


const http = require('http');

const server = http.createServer((req, res) => {
  if (req.url === '/') {
    res.end('Hello');
  }
});

server.listen(3000);

Express simplifies this dramatically:


const express = require('express');
const app = express();

app.get('/', (req, res) => {
  res.send('Hello');
});

app.listen(3000);

Express removes boilerplate and provides a clean structure.

Core Concepts of Express.js

1. Creating an Express Application

Install:


npm install express

Basic app:


const express = require('express');
const app = express();

app.listen(3000, () => {
  console.log('Server running');
});

Here:

  • express() creates the app
  • app.listen() starts the server

2. Routing

Routing means defining how the server responds to requests.

HTTP Methods

Common methods:

Method Purpose
GET Retrieve data
POST Create data
PUT Update entire resource
PATCH Partial update
DELETE Remove data

Example:


app.get('/users', (req, res) => {
    res.send('Get users');
});

app.post('/users', (req, res) => {
    res.send('Create user');
});

3. Request and Response Objects

Every route gets:


(req, res)

Request (req)

Contains incoming request data.

Examples:


req.params
req.query
req.body
req.headers

Example:


app.get('/users/:id', (req, res) => {
    console.log(req.params.id);
});

If URL is:


/users/10

Then:


req.params.id === "10"

Response (res)

Used to send data back.

Examples:


res.send()
res.json()
res.status()
res.redirect()

Example:


res.status(200).json({
    message: 'Success'
});

4. Middleware (Most Important Concept)

Middleware functions run during the request-response cycle.

They can:

  • Modify requests
  • Validate users
  • Log requests
  • Handle authentication
  • Parse JSON
  • Handle errors

Structure:


(req, res, next)

Example:


app.use((req, res, next) => {
    console.log('Request received');
    next();
});

next() passes control to the next middleware.

Types of Middleware

Application Middleware


app.use(...)

Route Middleware


app.get('/admin', middlewareFunction);

Error Middleware


app.use((err, req, res, next) => {
    res.status(500).send('Error');
});

Built-in Middleware

Express includes:


express.json()
express.static()
express.urlencoded()

5. Parsing Request Body

To read JSON data:


app.use(express.json());

Example:


app.post('/users', (req, res) => {
    console.log(req.body);
});

Input:


{
    "name": "John"
}

6. Serving Static Files

Example:


app.use(express.static('public'));

If public/logo.png exists:


http://localhost:3000/logo.png

works automatically.

7. Route Parameters

Dynamic routes:


app.get('/products/:id', (req, res) => {
    res.send(req.params.id);
});

URL:


/products/50

Result:


50

8. Query Parameters

Example:


/users?page=2

Code:


req.query.page

9. REST API with Express

Example:


const users = [];

app.get('/users', (req, res) => {
  res.json(users);
});

app.post('/users', (req, res) => {
  users.push(req.body);
  res.json(users);
});

Express is extremely popular for REST APIs.

10. Express Router

Large apps split routes into modules.

users.js


const router = require('express').Router();

router.get('/', (req, res) => {
  res.send('Users');
});

module.exports = router;

app.js


const usersRouter = require('./users');

app.use('/users', usersRouter);

This improves scalability.

11. Error Handling

Centralized error handling:


app.use((err, req, res, next) => {
    console.error(err);
    
    res.status(500).json({
        error: 'Internal Server Error'
    });
});

Throw error:


next(new Error('Something failed'));

12. Template Engines

Express can render HTML dynamically.

Popular engines:

  • EJS
  • Pug
  • Handlebars

Example:


app.set('view engine', 'ejs');

res.render('home', {
  name: 'John'
});

13. Authentication

Often used with:

  • JWT
  • Sessions
  • OAuth

JWT example:


const jwt = require('jsonwebtoken');

Middleware example:


function auth(req, res, next) {
    const token = req.headers.authorization;
    
    if (!token) {
        return res.status(401).send('Unauthorized');
    }
    
    next();
}

14. Database Integration

Express commonly works with:

  • MongoDB
  • PostgreSQL
  • MySQL
  • Redis

Popular ORM/ODM:

  • Mongoose
  • Prisma
  • Sequelize

Example with MongoDB:


const mongoose = require('mongoose');

16. Express Request Lifecycle

Flow:


Client Request
   ↓
Middleware
   ↓
Route Handler
   ↓
Response

More detailed:


Request
 → App Middleware
 → Route Middleware
 → Controller
 → Error Handler
 → Response

17. Example Full API


const express = require('express');

const app = express();

app.use(express.json());

const users = [];

app.get('/users', (req, res) => {
  res.json(users);
});

app.post('/users', (req, res) => {
  users.push(req.body);

  res.status(201).json({
    message: 'User created'
  });
});

app.listen(3000, () => {
  console.log('Server started');
});

Advantages of Express.js

Simple

Minimal syntax.

Fast Development

Easy to create APIs quickly.

Huge Ecosystem

Many middleware/plugins.

Flexible

No strict architecture.

Massive Community

Lots of tutorials and packages.

Disadvantages

Minimal by Default

You configure many things manually.

Callback-heavy

Older codebases can become messy.

Not Opinionated

Can lead to inconsistent project structures.

       ↓
Express API
       ↓
Database

  • Express processes request

Performance

Express is:

  • Lightweight
  • Non-blocking
  • Event-driven

Because Node.js uses an event loop.

Good for:

  • APIs
  • Real-time apps
  • I/O-heavy applications

Less ideal for:

  • CPU-heavy computations
