Node.js + Express JSON middleware

In Node.js + Express, middleware is one of the most important concepts. It is the foundation behind request handling, authentication, logging, error handling, and even routing behavior.

Below is a detailed explanation of Express middleware in JSON-style structured breakdown + practical examples.

📦 1. What is Middleware in Express?

Middleware is a function that runs between the request and the response.

It has access to:

  • req (request object)
  • res (response object)
  • next() (function to pass control)

Simple definition:

Middleware = a function that can modify request/response or stop/continue the request flow.

🔁 2. Middleware Flow (Concept)


Client Request
     ↓
Middleware 1 (log)
     ↓
Middleware 2 (auth)
     ↓
Middleware 3 (validation)
     ↓
Route Handler
     ↓
Response sent

Each middleware decides:

  • pass → next()
  • stop → send response
  • error → next(err)

⚙️ 4. Types of Middleware in Express

1. Application-level middleware

Runs on every request or specific routes.


const express = require('express');
const app = express();

app.use((req, res, next) => {
  console.log(`Request Method: ${req.method}`);
  next();
});

JSON view:


{
    "type": "application-level",
    "scope": "global or route-specific",
    "usage": "app.use()"
}

2. Router-level middleware

Used inside express.Router().


const router = express.Router();

router.use((req, res, next) => {
  console.log("Router middleware triggered");
  next();
});

3. Built-in middleware

Provided by Express.


app.use(express.json());
app.use(express.urlencoded({ extended: true }));

JSON:


{
    "express.json": "Parses JSON request body",
    "express.urlencoded": "Parses form data"
}

4. Third-party middleware

Installed via npm.

Example:


npm install morgan
            

const morgan = require('morgan');
app.use(morgan('dev'));

5. Error-handling middleware

Special middleware with 4 parameters:


app.use((err, req, res, next) => {
    console.error(err.stack);
    
    res.status(500).json({
        success: false,
        message: err.message
    });
});

🧪 6. Example: Full Middleware Pipeline


const express = require('express');
const app = express();

// 1. Parse JSON body
app.use(express.json());

// 2. Logger middleware
app.use((req, res, next) => {
  console.log(`[LOG] ${req.method} ${req.url}`);
  next();
});

// 3. Auth middleware
app.use((req, res, next) => {
  if (!req.headers.authorization) {
    return res.status(401).json({ message: "Unauthorized" });
  }
  next();
});

// 4. Route
app.get('/profile', (req, res) => {
  res.json({ user: "John Doe" });
});

// 5. Error handler
app.use((err, req, res, next) => {
  res.status(500).json({ error: err.message });
});

🔐 7. Middleware Behavior (Important Concepts)

1. Blocking request


return res.status(403).json({ message: "Forbidden" });

2. Passing control


next();

3. Passing error


next(new Error("Something failed"));

🧠 9. Mental Model (Very Important)

Think of Express middleware like a factory conveyor belt:

  • Request enters
  • Each station (middleware) modifies or checks it
  • If something fails → stop line
  • If everything passes → final product (response)
