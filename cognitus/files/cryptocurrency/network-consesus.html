Network consensus

Network consensus means:

A group of computers in a network agree on what is true and what should be recorded.

In cryptocurrency, this is extremely important because there is no single bank deciding which transactions are valid.

Simple example

Imagine 5 people have copies of the same notebook:


Alice's notebook
Bob's notebook
Carlos's notebook
David's notebook
Eve's notebook

Everyone records transactions.

Now Paul says:

"I sent 2 BTC to Alice."

The network checks whether Paul actually has 2 BTC and whether the transaction follows the rules.

If the network agrees:


Paul → Alice
 2 BTC
   ↓
Everyone records it

Now all the notebooks have essentially the same history.

That's consensus.

Why do we need consensus?

Imagine there were no consensus mechanism.

Paul could tell one computer:

"I sent 2 BTC to Alice."

and another:

"I sent the same 2 BTC to Bob."

You would have:


Computer A: Paul → Alice  2 BTC

Computer B: Paul → Bob    2 BTC

Now the network disagrees about reality.

That's a major problem for digital money.

Consensus solves this by providing rules for determining:

Which transactions are valid and what the official history of the network is.

Bitcoin's consensus

Bitcoin uses a mechanism called Proof of Work (PoW).

Very roughly:


Transactions
     ↓
Bitcoin nodes verify them
     ↓
Miners compete to produce a block
     ↓
Network verifies the block
     ↓
Block added to blockchain
     ↓
Network continues from there

The important idea is that no single computer gets to simply declare the truth.

The network follows predetermined rules.

Think of it like a classroom

Imagine 1 teacher vs. 1,000 students.

If the teacher says:

"The answer is 42."

Everyone accepts it because the teacher has authority.

That's somewhat like a centralized system.

Now imagine there is no teacher.

The students need a procedure for agreeing on the correct answer.

They follow predefined rules and verify each other's work.

That's closer to decentralized consensus.

Consensus ≠ everyone voting

This is an important distinction.

When people hear "consensus," they might imagine:

"51% of computers vote YES."

That's not quite how Bitcoin works.

Bitcoin nodes independently verify transactions against the protocol's rules.

The network's consensus emerges from everyone following the same rules and converging on the same valid blockchain history.

The big picture

This connects directly to your previous question about why people can trust cryptocurrency:

Cryptography → proves authorization

Consensus → determines what transactions are accepted

Blockchain → records the agreed history

Scarcity → limits the asset

Network adoption → creates demand

Demand → contributes to market value

So consensus is essentially the mechanism that answers:

"In a decentralized system with no bank in charge, how do all these computers agree on what happened?"
